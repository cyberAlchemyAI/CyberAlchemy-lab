# Protected release inputs and exact semantic graph, candidate v2

This component separates original source/profile/history proof bytes, protected host dependencies, public package bytes, and semantic Artifact records. It creates no admission, governing role, owner response, installation, native execution, or live-store authority.

`ProtectedReader(selector_bytes, grant_bytes, independently_selected_anchor)` checks the exact original source/profile/cut and current technical custody, then reads only selected regular files through no-follow directory/file descriptors. Controls must be in a privately owned directory with mode 0700 and files with mode 0600. Root, file ownership, device/inode, mode, size, digest, and attachment are checked again at the boundary. The integrating host must supply the anchor from its independently authenticated custody route and retain its original host guards; a public request cannot select its own anchor.

Use `with reader.boundary(): ...` for the full entry/exit guard. `reader.verify()` keeps every original table row and its order. Mandatory source/profile files, profile external execution dependencies, composite source/profile/schema rows, and original native/ABI/wheel host selections are verified separately. Missing rows or missing original locators refuse closure. Original locators are never redirected to a newer installation. The protected JSON parser has its own 64 MiB bound, and larger selected files can be hashed without collecting their bytes. Original API frame and ordinary Vault limits remain 1 MiB.

`verify_graph(reader, policy_file_id, declared_edges, root_refs, independently_selected_graph_anchor)` validates selected records against exact original registered carrier schemas and discriminator selectors. It uses the pinned original native identity fallback and category/version rules. Definition and foundation records may have different identity fields, absent `kind`, or legitimate empty relation-role lists. All seven original foundation declarations remain separately verified proof; they are not fabricated domain nodes. Registered Artifact Type instances use the actual original registered-entry schema fragment.

Reference dispositions bind every selected original schema location, including nested fields, arrays, composition, conditional schemas, literal `ref`, and qualifier fields. Only independently declared semantic-node dispositions form graph dependencies; proof and current-context references are checked separately. Original descriptor direction/role rules and original Relation Kind endpoint/qualifier contracts govern actual relations. The graph rejects omitted or duplicated edges, wrong current versions/kinds, disconnected nodes, and semantic cycles. Public refusals contain bounded messages instead of protected instance values.

The closed controls are `protected-selector.schema.json`, `custody-grant.schema.json`, and `semantic-policy.schema.json`. Unknown binding kinds and extra control fields are refused. Reference recursion and patterned key selectors require an explicit successor contract and are refused instead of silently truncated; the current 143 original registered schema selectors do not require that extension.

Focused qualification uses newly owned technical custody and explicit technical reference dispositions. It proves component behavior for the selected inputs, including actual varied original carrier bodies and exact declaration bytes. It does not prove the final package's complete per-record production dispositions, actual native history, API17 integration, current governing roles, or human usefulness. Original frozen v1 and API16 evidence remains unchanged. See `CONTRIBUTION.json` for exact input/result bindings and remaining integration work.

# Original artifact source to native context representation

This candidate independently selects the frozen original-body source and the
existing rich native executable. It retains the prior mapping policy and all
twenty original assertion methods. A new namespace supplies the source reader,
records and eligibility classes without changing old archives, modules or keys.

Fifteen selected current Artifact instances become native node representations;
ten materialized Typed Relations become directed edge representations. All 25
semantic events have separately sealed, exact governance joins. Schema bytes,
Definition witnesses, signatures, axis, qualifiers, source cut and body hashes
retain their distinct roles. Native node identity is the declared hash of an
Artifact Reference header. Its record hash is the actual body byte hash. These
two hashes do not represent the same object.

The newly authored original bodies are read from their retained content entries.
Generated consequence records keep their explicitly declared inherited encoding.
The mapping preserves the full source closure and one disposition for every
captured subject. A retained old Assignment tied to an older instance remains
diagnostic metadata outside this new context selection. The fresh Assignment
targets its new Profile; neither record supplies current host permission.

Source HEAD sequence, native semantic cursor and governance cursor are distinct
coordinates. Every edge retains the already declared exact signature, endpoint
tuple and qualifiers. No payload reference creates an implicit connection, and
no ontology representation admits its underlying Artifact.

Native sealing and cold reading use actual separate processes. Outputs and their
original native serialization are frozen into a private package before checks
consume them. This retains the explicit native read selector
`test-complete-profile/v1`; it does not claim an admitted production selector or
SLA. Context/Ontology View carrier outputs, independent current host permission,
ephemeral Agent/Session execution and the complete public API remain subsequent
obligations. The source Assignment's original absolute interval is not reset.

## Preserved boundaries

- Current Relation Kinds, endpoint contracts, Actor, source cut, writable carrier,
  durable key and complete affected successor list are independent host inputs.
- Candidate content, exact pair evidence, finite qualifier domains, the predecessor
  signature, all ordered Decision cores and pending semantic review stay distinct.
- Both global and ontology-local preparation create zero registrations and zero
  relation instances. The program issues no semantic verdict or owner outcome.
- PASS tokens cannot replace substantive complete noncollapse comparisons.
- Generic Typed Relation and a specialized carrier cannot become two writable
  authorities for the same pair.

## Remaining public integration

The selected host must validate the complete actual current inventory and carrier
successor impact, enforce the original schema/core and permission checks, verify
the pending review's actual source bindings, and dispatch through a separately
declared signed policy. It must journal exact candidate outcomes, prevent duplicate
effects and expose pending/indeterminate keys without redispatch. Full original
positive/negative/retry/recovery, scope, budget, expiry and tamper cases are still
required. These unit cases do not satisfy those public obligations.

Actual R08 owner outcomes and subsequent exact admission remain separate from
this preparation. Candidate readiness leaves unregistered connections unwritable.

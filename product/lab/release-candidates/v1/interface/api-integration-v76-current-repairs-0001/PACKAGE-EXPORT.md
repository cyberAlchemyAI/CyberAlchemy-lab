# Authenticated package export

The public `package.export` operation uses the original archive-transfer and
managed-publication kernels. Its independent local policy selects the exact
export plan, source cut, destination device/inode, scope manifest, complete
material graph, byte and generation budgets, export contract and privacy review.
The request supplies no permission or filesystem destination.

Controlled candidate roots require an independently selected original native
ChangeProposal with matching Actor, key and cut. Every target remains a root;
native validation must pass without gaps. Original schemas, stable Decision cores,
target metadata and all native resolved domain references must occur in the graph.
Current retained dependencies require their exact signed-source originals plus
the original archive and replay profile. Unknown native obligations block export.

Current admitted-source roots require exact current source references and the
independently selected original signed archive/profile basis. These are admission
observations within the selected source namespace. They confer no permission or
admission in another target. Source conformance and foreign trust resolution remain
separate obligations. The original archive kernel retains its explicit statement
that packaging itself does not verify source admission.

Material origins are closed: exact candidate/current artifact, original carrier
schema, selected public source proof or native proposal input. This handler accepts
JSON originals. Binary/text-specific disclosure adapters remain future work; no
opaque private material receives an invented privacy verdict. The original kernel
verifies complete reachability, dependency order, every encoding and privacy
selection, original bytes and package budgets.

Pure preparation stages evidence and exits the original source scope before any
managed generation is created. Publication uses actual source and current policy/
clock callbacks. A complete original File Materialization Receipt binds the
generation, manifest and package bytes. Interrupted publication returns uncertainty
and requires reconciliation. Exact retry verifies the recorded generation with
read-only package inspection; it never creates a missing generation or repairs a
corrupted one. Operation inspection preserves any recorded uncertainty.

This successor adds one handler while retaining all34 original public contracts
and293 inherited test methods. Actual controlled-candidate, signed-source and
retry journeys and the negative permission/privacy/closure/recovery suite remain
required. General foreign/admitted-source import, all remaining public operations,
broader carrier authority/reference adapters, real pilot and final S02/R08 remain
unfinished. No candidate test invents an owner outcome or canonical admission.

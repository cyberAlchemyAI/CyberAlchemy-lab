# Context and ephemeral Session API successor

Candidate construction. This package retains the seven existing operations and
implements the four original Context/Session contracts on the selected fresh
participation branch. Its externally selected profile retains all 34 original
wire operation schemas. The remaining 23 operations, complete release journeys,
actual human pilot and final S02/R08 review remain required.

The private host grant selects a recognized controlled development Principal,
one owned workspace and the exact source branch. Ed25519 one-use transport proof
is independent of source recognition. Role labels, Profile, Assignment, returned
views and classification do not grant permission. The original absolute Assignment
period is independently bound and never reset. The selected Agent Capability and
Implementation provide only original-source reading; no Tool action is dispatched.

Context generation consumes the actual signed source and rich native replay at
separate coordinates. Thirty original-schema-valid carriers and their source
provenance are retained as private derived objects. The Context Delivery binding
is SHA-256 over its exact returned UTF-8 message span, referenced as
`context-delivery:<context_view.version_ref>`. Enclosing source file hashes and
selected-body hashes remain distinct. Stable host grant identity is
`host-policy-sha256:<policy hash>`, independently compared to current private bytes
at Session consumption. A new nonce-authenticated connection may read the same
owned metadata; it cannot reconstruct a lost Agent.

Opening rechecks actual views, permission, participation, source cut, Profile,
Implementation and the exact source-reader Capability after claiming the durable
API idempotency key. A fresh Machine Instance and one Session are allocated.
Scoped Scheme and Value inputs produce a candidate Classification Assignment for
that exact instance revision and Session period. The classifier Method is an
explicit hash-bound protocol-method reference; creation attribution is the actual
host opening request, separately from later Agent Actions. Classification source
inputs and annotation remain candidate evidence for final review.

Seven separate candidate Typed Relation records retain exact local/source/view
endpoint revisions, original carrier hashes, existing closed Relation Kind pairs,
axes and qualifiers. They are operational candidate records, not canonical
admission or native ontology replay events. The Agent and classification snapshots
remain immutable; observed liveness and termination are separate metadata.

RAM notes live only in the resource. They are bounded and zeroed on close, expiry
or observed source invalidation. A deadline timer performs disposal without
waiting for another API request. Notes and their hashes never enter replies,
metadata, files or exports. Durable continuity is Project State through freshly
verified Context and Ontology Views.

Session state comparison uses the exact most recent opening or disposal receipt:
`session-state:<session_ref>` and its original returned-message byte hash.
`session.inspect.last_receipt_binding` exposes that comparison; it does not expose
a Session memory body. Close verifies Principal scope, Agent identity and that
exact state, without requiring fresh Project State. Local host termination policy
remains current and separate. Whole-process shutdown disposes every held resource
before dropping authentication. Corrupt metadata still triggers RAM erasure, while
verified disposal is not fabricated from missing metadata or a lost process.

The owned workspace records API claims before effects. Same fingerprint returns
the recorded historical outcome under current read permission; changed inputs
conflict, pending keys require inspection, and lost/closed Sessions never resume.
Cold metadata can describe an active recorded receipt as indeterminate but cannot
restore RAM, infer disposal or reuse an Agent identity. Session custody has an
exclusive process lease. API calls on one stdio connection are serialized.

Validation includes the seven retained operations, all four new operations,
original received bytes, exact retries, pending records, actual Machine
classification, declared connection closure, negative authority/source/selection
cases, private memory checks and real expiry. Actual process interruption/cold
reconstruction and full release integration remain separately required.

The successor uses its own Python package namespace. Frozen source and view
producers keep their original v12 dependency module origins and exact bound
files; a global module-name collision cannot substitute successor code into
a predecessor producer. Original dependency origins have explicit guards.

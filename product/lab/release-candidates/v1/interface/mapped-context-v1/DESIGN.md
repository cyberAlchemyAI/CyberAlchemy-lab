# Same-cut mapped ontology projection

This candidate projects fifteen current domain Artifact instances and ten current
Typed Relation instances from the exact signed fresh-participation branch into
native semantic and governance streams. The source cut and native cursors are
separate, explicitly bound coordinates. Artifacts retain their original carrier,
identity, revision, byte hash and source locator. Native nodes represent those
artifacts; they do not replace or admit them. Project/Product endpoint kinds use
the already selected explicit carrier mapping.

A frozen projection protocol selects the native runtime's closed subject and
connection property profiles. It creates no admitted Artifact Type or Ontology
Profile. Node identity is a hash of the exact Artifact Reference; relation identity
is a hash of the exact Typed Relation reference. Every edge comes from a separately
materialized current Typed Relation with an existing closed signature, exact
endpoints and qualifiers. Payload references do not invent edges. Axis, signature,
qualifiers and Definition witnesses remain in the mapping index and their hashes
are retained in native properties. Native governance joins require exact semantic
event references and remain candidate, non-authoritative.

The actual native Rust executable seals events and performs cold replay. It is
independently hash selected. All byte inputs, event families, requests and original
native output are bound in a derived package before dependent use. This is a
projection foundation: generated Context/Ontology View carrier bodies, authenticated
host permission, classified ephemeral Session resources and public APIs remain
separate obligations. No historical Session body or private key is projected.

The existing native selector exposes only test-complete-profile/v1. It is used
explicitly as that read projection selector, separately from the closed domain
subject and connection property profiles. No Product projection SLA or admitted
production selector is inferred.

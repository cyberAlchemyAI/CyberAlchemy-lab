# Prospective Governed Model candidate option

This is a separately identified, unselected type and meaning proposal for the ten original non-executable W08 workflow blueprints. No blueprint is claimed implemented or executed. Original model owners, scopes, original control bytes, and rule/proof references remain attributable. No Implementation, Decision, or predecessor is invented.

The admitted GovernedModel Definition describes an explicit representation of concepts, rules, structures, or behavior and separates that representation from runtime, Implementation, truth, decision, and authority. It does not itself require an already instantiated relationship. The original v1 schema independently requires `relation_refs.minItems=1`; all ten original empty-relation models still fail that exact v1 constraint.

The proposed `cal.artifact-type.prospective-governed-model/v1` namespace makes the change explicit. It requires `payload.model_disposition="prospective-design"` and proposes `relation_refs.minItems=0`. It preserves every other original schema constraint and all original permitted relationship role/direction/counterpart semantics. The distinct discriminator and namespace prevent qualification from being transferred to v1. Exact deltas, Definition bindings, and candidate bytes are in `proposal.json`.

`validate_proposal.py` checked the exact declared delta, original v1 refusal, original owner/scope/rule preservation, ten candidate shapes, and nonprospective/extra-authority/wrong-role negatives. The registered declaration has only the shape of the original ArtifactType/v3 entry contract; actual native namespace, source/cut, current owner, and preparation are not qualified.

An accountable Artifact Type/Definition owner must decide whether this prospective-only carrier and its cardinality are appropriate before any runtime selection, native proposal, admission, or release. The current records assert no answering principal or approval. Existing R08 and separate operation/activation gates remain required.

This option excludes schema-only controls, receipts, confidence vocabulary, source/private-use permissions, archive provenance, endpoint alias approval, and actual workflow execution. Those members retain separate meaning-specific dispositions. T10 remains incomplete.

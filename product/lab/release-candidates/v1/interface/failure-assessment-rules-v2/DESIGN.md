# General failure assessment rules

Status: candidate implementation. Authority effect: none.

This is the pure rule stage for the original `failure.assess` API. The W05
controlled episode remains immutable and supplies no general API qualification.

## Inputs and results

The caller pins the complete rule source manifest, supplies exact original
five-axis artifact references and bytes, and selects the original request,
candidate Failure Assessment, evidence basis and optional incident threshold.
Original carrier and request schemas remain unchanged.

The kernel checks the occurrence, its subject and expected boundary, the exact
classification assignment and its Scheme/Value/Failure Mode, exact Hypothesis
references and evidence provenance. Classification uses the existing qualified
21-case rule primitive, including unknown-rule and independent-axis behavior.

Occurrence, mode, cause hypotheses, impact, containment, recovery and uncertainty
are copied independently from the authored assessment. Each axis has explicit
original-byte evidence bindings in a separately selected basis object. A shared
evidence item may inform multiple axes; it does not establish a shared conclusion.
The kernel asserts no cause confirmation, recovery success or control effectiveness.

## Optional incident threshold

The candidate threshold has one implemented predicate:
`minimum-evidenced-occurrences`. It evaluates a declared exact cohort and minimum
count after verifying every member's detection evidence. The host must independently
select its binding and scope. Unknown predicates produce `not-evaluable`; a missed
threshold produces `fail`. Neither result creates an Incident or changes the
authored assessment axes. Counting controlled occurrences supplies no production
applicability or impact/severity inference.

## Required public composition

Before public use, a successor host must bind these exact source bytes and select
the basis and threshold through authenticated current policy. It must check the
Actor, scope, cut, permissions, budgets, deadline, signed routing, original
ChangeProposal schemas and independent stable Decision cores. It must construct
the complete current/prospective record set, preserve current source checks at
entry and exit, and journal known rule failures separately from uncertain effects.
Exact retries must inspect recorded results; pending or uncertain keys never
redispatch. These obligations are not performed by this pure kernel.

The original API v37 is frozen. This package changes neither its handler list nor
its qualification. All 34 public contracts and 46 plan tasks remain obligations.

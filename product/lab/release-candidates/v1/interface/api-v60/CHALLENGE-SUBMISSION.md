# Authenticated candidate challenge submission

`challenge.submit` prepares a new open Challenge Event under the original public
request and Change Proposal contracts. The host independently selects the exact
Challenge Contract, current Principal, authorized subject revisions, grounds,
evidence sources, routes and finite submission window. Request fields and an
eligibility report never grant authority.

Preflight resolves original current signed Principal/contract/evidence records,
the exact current or historical challenged revision, required evidence kinds,
private disclosure scope and contract routes. Receipt evidence must name an
actual completed source-guarded validation bound to this frozen host. Every
requested evidence byte must match its independently selected original. The
caller eligibility calculation is compared with an independently executed result.

The candidate's original noncanonical bytes are retained. Its Principal, subject
identity/version, contract, grounds, ordered evidence, routes and open state must
match the actual request and selected sources. Resolution remains `none`; residue
and successors remain empty. No implicit graph connection is created. The actual
native custody/core/preparation functions revalidate the exact target without
changing the source projection. Evidence is staged in the original bounded
buffer and committed only after source/permission exit checks.

The original durable claim, fingerprint, recorded-result, retry and recovery
machinery is used. A changed fingerprint conflicts; a pending key never
redispatches. Refused preflight writes no files. An exact retry returns the saved
outcome after current read authorization, with no new candidate creation.

This candidate does not adjudicate factual grounds, resolve a challenge, admit
the event, mutate the subject or rewrite history. It supports the explicitly
selected operator Principal path; assigned Machine challenger provenance remains
required for the full Agent path. Contract policy/period strings are retained
for owner handling and do not become automatic decisions or deadlines.

The new owned fixture has a finite two-hour reader/routing window declared at
initial provision. Original clocks and historical grants remain unchanged.
Private test signing keys and workspaces are disposed by their owning context.
All inherited test bodies and all34 original public contracts are preserved.
Whole-current-API qualification remains required.

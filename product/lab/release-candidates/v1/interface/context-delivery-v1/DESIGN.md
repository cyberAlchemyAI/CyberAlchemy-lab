# Source-bound Context and Ontology delivery

This candidate generates real Context Request/View, Ontology/Node/Edge/Cut/View
carrier bodies from the exact signed fresh-participation branch and its native
projection. Representation and represented Artifact Definitions are separate.
Every global edge retains its exact Typed Relation, signature, axis and qualifiers.
Calculated carriers cannot serve as native replay events or confer authority.

The development host separately provisions a private, UID-owned permission file
and a transport public key. A fresh nonce proof authenticates one connection.
Principal recognition in source is distinct from this host authentication and
permission. The controlled development Principal does not impersonate a human
or canonical repository owner. Policy references have exact frozen protocol
bodies, outside caller JSON. The absolute Assignment period is never reset.

The source policy selects the fresh participation closure, current Project State
and declared connection closure. Original source bodies are verified privately;
whole source archives, private keys and historical Session memory are not public
view material. Context included-material hashes bind enclosing original files
and explicit selectors. Artifact References retain selected-body byte hashes.
Both coordinates and encodings are preserved in an independent provenance index.
Operational Lesson selection checks the actual current signed catalog; no lessons
are invented. Current applicable lessons outside this projection require explicit
projection closure before readiness.

Ready requires real generated schema-valid views, enforced source scope, current
host permission, current source/native byte closure, exact request/Actor bindings,
exclusions, budgets and expiry. Outputs are immutable and hash selected before
later consumption. A delivered view is not itself Agent creation. All original
public Context/Session API wiring and ephemeral resource custody remain required.

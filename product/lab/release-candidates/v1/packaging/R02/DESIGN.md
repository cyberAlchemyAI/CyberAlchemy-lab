# R02 candidate packaging

The supported environment is the exact recorded CPython, SQLite, Linux x86_64 and libc tuple. Eight selected upstream wheel versions and their hashes form the complete third party dependency closure. Runtime execution uses `python3 -I -S` and the selected extracted wheel files; global site packages, pip, network resolution and dependency installation hooks are excluded. Standard library and native ABI belong to the separately fingerprinted environment.

The immutable source payload retains canonical relative paths for selected D74/D75 source captures, runtime v1/v2, replay and branch-transition code, profiles, schemas and explicit proof entrypoints. It is a foundation packaging selection. R03 still owes the complete product API; S02 must bind its eventual release payload. Installer preparation grants no store or owner authority.

Installation is restricted to an independently supplied owned candidate directory. Exact staging bytes are rechecked before a Linux atomic no-replace directory publication. Existing empty, foreign and symlink destinations are rejected. Exact already installed packages support verified idempotent retry. Unknown or incomplete staging directories remain available for investigation; changing the package pin selects a different staging identity.

Upgrade creates the signed C05 candidate successor with independently reviewed exact carry/exclude selections. Original signed parent transactions remain byte-identical; the successor does not acquire parent admission or signatures. Old code, its dependencies, parent archive and independent replay pins remain rollback inputs. Rollback means selecting and replaying that retained old branch/code; it never rewrites HEAD or deletes successor history. No permanent activation is performed.

Export performs an uncached verified read, chooses only committed branch files and checks the same cut afterwards. Unrelated private key files, caches and Session notes are excluded. Selected payloads containing private keys or short memory are rejected, including captured base64 source data. Schema declarations of Session fields are distinct from actual memory. Recovery uses an independently pinned archive, preserves original bytes and rejects overwrites; cold full replay independently validates restored signatures, schemas and cuts. No Session is restored.

The R02 receipt closes isolated candidate packaging criteria only. Final owner permission, human journeys, full API acceptance, actual admitted operation and final release remain governed by S02/R08/A01-A04.

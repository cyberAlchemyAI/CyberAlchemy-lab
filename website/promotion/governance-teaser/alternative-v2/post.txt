Governance that stops at permissions and privacy compliance leaves a question unanswered: what does “complete” mean?

Customer 1 wants an export of its active database entries. Both agents use Snapshot 1, a database snapshot saved at one time.

Authority. The service owner accepts Definition v1: every ID matching Customer 1 AND Active status must be in the file. Each agent gets separate permissions.

Provenance. Review 1 links Definition v1, Snapshot 1, Export code v1 and its exported file. The reviewer checks every selected ID against that file and finds 200 missing out of 10,000. The export fails Definition v1. A new agent receives this linked review with its own permissions.

Lifecycle. Definition v1 is accepted. Export code v1 still awaits acceptance. A revised version needs a fresh review and owner acceptance, then separate permission for customer release.

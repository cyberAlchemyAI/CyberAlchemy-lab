# Owner intent: contextual framings

The CyberAlchemy-v2 product should create systems that remain easy to use while
ergonomically increasing human cognitive capacity and productivity. Necessary
complexity should be carried by the system rather than transferred to the
person operating it.

Within the Agent Reasoning Engine, contextual framings should turn distilled
knowledge and carefully bounded analogies into perspectives that help a person
understand, decide, or act with less cognitive effort.

The capability must not hide load-bearing constraints, uncertainty,
provenance, disagreement, or authority boundaries. An analogy is a partial
mapping, not literal equivalence. A framing is valid only for its named
consumer, objective, context, source epoch, and expiry conditions.

Status: owner-directed candidate intent. It is not a canonical definition,
runtime acceptance, conformance evidence, or effect authorization.

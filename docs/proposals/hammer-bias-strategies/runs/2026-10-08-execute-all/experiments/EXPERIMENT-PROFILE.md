# Native controlled decision experiment

Profile: generic-sigil-style controlled exercise for the local anti-hammer strategy catalog. Candidate package: parent run README.md. This is a native helper execution, not a CLI adapter. The user explicitly selected all strategies and their exercises.

Three arms: capability-first, outcome-first, inversion-and-expansion. All receive exactly the same twelve cases and measurement rules; no arm sees peer outputs or evaluator internals. One native agent output per arm is collected. These are independent runs, not randomized replicated estimates. Arm effects are confounded with stochastic model variation; identical results are retained. No claim of human behavior, production improvement, or statistical superiority follows.

Measurements are predeclared in each case: feasibility against explicit constraints, observed selection of a non-dominated action, correct logical entailment, outcome/causal explanation, and cost where stipulated. Quantitative score is a coverage summary; it is not a universal utility function. Parent runs a deterministic scenario evaluator and separately reviews reasons. All case actions are text choices; no external effect is executed.

Quality bar: twelve substantive decisions per arm; valid action IDs; rationales cite supplied facts; no tool method is forced to win; preserve ties; missing outputs remain incomplete. Save prompts, outputs, evaluator, case hashes, and report. Native runtime helper identifiers and completion receipts are recorded by parent.

# Strategies for generating novelty during analysis

The next investigation asks whether a deliberate transformation produces a useful possibility that ordinary analysis and a generic request for creativity would miss. A possibility can be a mechanism, a causal hypothesis, a discriminating question, or an explicitly changed problem frame. The strategy package is prepared; its comparative experiment has not run.

The [previous study](../runs/2026-10-08-execute-all/SYNTHESIS.md) found identical choices in its twelve fixed-choice cases and overlapping mechanisms in two open cases. Those results motivate an open-generation experiment. They do not establish that the earlier methods lack creative value. The user's rejection of the first sentence set supplies a separate qualitative requirement: an output should make another possibility imaginable, beyond restating the diagnosis.

## The change to the process

Give generation a concrete operation: move a function, reverse a causal relationship, remove a dependency, create an interaction, or invent a testable capability. Save the resulting alternatives before selecting or compressing them. Ask what new observation, action, or explanation each makes available.

The smallest useful unit is one **traceable generative move**:

> Baseline → challenged assumption → transformation → changed mechanism or question → constraint disposition → distinguishing observation → next probe.

A clever line can seed that move. For example, “Pay the hammer for what holds together” suggests changing the provider's incentive. A candidate must then say what reward changes, what behavior it predicts, how it preserves the outcome, and what gaming would defeat it. The sentence itself supplies none of that evidence.

Compare novelty against a declared, frozen baseline. “Absent from this archive” is the appropriate claim; worldwide originality has not been investigated. More words, more agents, unusual metaphors, and additional option names do not themselves count.

## Twelve strategies to investigate

| ID | Generative operation | Question that opens it | What must change |
| --- | --- | --- | --- |
| N01 | Move the function | Could the material, interface, or artifact do the tool's job? | Function carrier and causal path |
| N02 | Find demand created by the solution | Does our intervention help manufacture the need for itself? | A feedback relationship and prediction |
| N03 | Remove the intermediate need | What could fit differently so this task need not happen? | A dependency, with its obligations preserved |
| N04 | Turn the attack into an input | Could the defeating force become information, energy, or control? | A concrete conversion mechanism |
| N05 | Remove a presumed prerequisite | What could work if this dependency disappeared? | A complete alternative dependency structure |
| N06 | Change the unit of the problem | What appears at another scale, time horizon, or relational boundary? | State variables, triggers, and recomposition |
| N07 | Transfer a distant mechanism | Which unlike system has a useful relationship to borrow? | A mapped relation and its transfer limits |
| N08 | Create a new interaction | What can two partial mechanisms do together that neither does alone? | An interface and predicted interaction |
| N09 | Activate an unused affordance | What else could an existing trace, property, or by-product do? | A property-to-operation relationship |
| N10 | Change what success rewards | What would the provider invent if rewarded for the maintained outcome? | Incentives and predicted behavior |
| N11 | Protect the anomaly | Which awkward case deserves a new explanation? | A discriminating explanation covering ordinary and unusual cases |
| N12 | Work backward from a future object | What capabilities would make this surprising object possible? | An explicit dependency chain and testable first capability |

The [strategy cards](STRATEGIES.md) give examples, probes, and failure tests. [catalog.json](catalog.json) carries the same records for later experiments. Several strategies deliberately extend the previous catalog; their relationship to earlier work is recorded. Twelve operators do not imply twelve independent mechanism families or twelve globally new inventions.

## Compose the techniques around the missing capability

**Open a different causal world:** Robot Talks identifies a tension; N02 investigates a feedback direction, N03 removes a presumed intermediate need, or N05 removes a dependency. The attack must name the assumption exposed and the opening it creates. Distill follows the generation window and preserves the differing mechanisms. Use [C1](dispatches/c1.dispatch.json).

**Build an unexpected capability:** N12 describes a speculative future object; N01 relocates its required function; N04 asks whether an attack could become a design input. The output is an enabling capability and a probe. Missing resources and relaxed premises stay visible. Use [C2](dispatches/c2.dispatch.json).

**Create a new interaction:** N07 supplies a mapped mechanism, N09 identifies an available affordance, and N08 proposes an interface between mechanisms. Compare the hybrid against both parents. Use [C3](dispatches/c3.dispatch.json).

These are candidate combinations, not demonstrated improvements. The [single-operator route](dispatches/single-operator.dispatch.json) supports the controlled comparison. A later bundle experiment can test interactions; a bundle winning would not identify which ingredient helped.

## Preserve the meaning of the lanes

In the existing two-lane dialectic, Lane Z develops the incumbent and challenges it with a sourced counterexample. Lane A develops another mechanism against the same underlying outcome. Robot Talks supplies independent concerns and makes contradictions inspectable. The new operator changes the work assigned to Lane A. It is a local extension to the investigation design, not a redefinition of either skill.

Constraint status is a separate classification from Lane Z/A. A commitment-preserving opening keeps the beneficiary, valued outcome, and hard constraints. An exploratory frame branch names what it changes and whose interests remain represented. A conditional branch that relaxes a hard constraint cannot win as a solution to the original task. Missing evidence is recorded as uncertainty, and a fixed constraint may legitimately yield no opening.

## Measure generation and preservation separately

The [protocol](PROTOCOL.md) holds the two-lane scaffold and neutral Distill stage constant. It compares ordinary analysis, a generic creativity instruction, and each specific operator. Cases provide evidence and constraints without action menus. Judges assess plain descriptions with method labels removed.

Record novelty, potential usefulness, constraint fit, observability, evidence status, and burden separately. Then check what survives Distill. A new question counts when it exposes a distinct observable difference; it need not already have an answer. Familiar but useful ideas remain useful, and speculative novelty remains speculative.

The prepared plan screens twelve operators and two controls, then checks up to two finalists on untouched cases. Its maximum is 104 scored run units, each with three generation calls, before review. One additional unscored format preflight is budgeted separately. This is a bounded research design, not a powered effectiveness study. [PROTOCOL.md](PROTOCOL.md) specifies launch prerequisites and resource limits. No new trial or live intervention is recorded as completed.

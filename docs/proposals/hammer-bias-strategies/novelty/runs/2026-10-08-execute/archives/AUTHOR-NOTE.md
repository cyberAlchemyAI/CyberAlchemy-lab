# Archive author note

These seven evaluator-only archives were authored independently from the seven supplied synthetic case files. Only P0.json, D1.json, D2.json, H1.json, H2.json, H3.json, and H4.json in this run's cases directory were read as inputs. No method instructions, catalogs, generation outputs, parent conversation, or web material were inspected. No additional agents were used.

Each archive contains four ordinary mechanism families and two ordinary diagnostic questions that a conventional analyst could propose. These are deliberately modest authored baselines, not empirical evidence, validated interventions, exhaustive mechanism inventories, or recommended correct solutions. Their causal paths are hypotheses subject to the recorded conditions and assumptions. Every archive records the SHA-256 of the exact source-case bytes used.

The archives are incomplete. A proposal missing from an archive cannot establish global novelty, historical priority, or absence from ordinary practice. Presence supplies an authored comparison family rather than proof that a proposal is correct or previously deployed. A match should concern the described actor, operation, target, and causal or observable relationship, not shared vocabulary alone.

Access is evaluator-only. Generation agents must not receive these archives or this reference content. H1-H4 remain sealed from prompt tuning and method selection; authoring their reference data does not authorize training or selection on those cases. The archive author returns only file counts and paths, without quoting held-out content.

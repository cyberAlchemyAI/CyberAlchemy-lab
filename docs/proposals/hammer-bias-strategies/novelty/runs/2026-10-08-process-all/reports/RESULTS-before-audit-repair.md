### Concrete examples and what to prepare differently

**P01:** Library relocation → stale locator → another search is a useful chain. It does not establish that the extra searching feeds back into further relocation. The kit chain, shared access → interrupted counts → omissions → checking, has the same missing return influence. Prepare the return arrow as a separately observable hypothesis, with an explicit no-loop outcome. [Library P01 raw](outputs/S1-r1-P01-A.json), [kit P01 raw](outputs/S2-r1-P01-A.json).

**P02:** Attacking assumed recipient verification produced: can existing private reservation evidence uniquely distinguish the reader from a household member? A small private check allows an unresolved result without promising that adequate records exist. It is useful construction from an attack, but ordinary critique reached the same question. [P02 attack and branches](outputs/S1-r1-P02-Q.json), [matched critique](outputs/S1-r1-critique-Q.json). Prepare an attack target plus a feasible replacement/removal/test, then compare against critique without that obligation.

**P03:** Exact kit-batch quantities turn a missed insertion into visible surplus, which triggers reopening the batch. An equally local unrestricted-stock rival distinguishes conservation as a signal from proximity alone. Miscounts create false alarms; overfill can cancel the signal. Exact staging, footprint and observation burden remained uncertain. [P03 kit raw](outputs/S2-r1-P03-A.json). Prepare conversion, false response and cancellation together.

**P04:** A divider range selecting a current exception-slip band gives a concrete interface. Keeping contents accurate while scrambling the link tests coupling; a current flat slip is a rival. The kit ledger similarly binds sample requirements to material tags and transfers. These proposals motivate an interaction experiment, with unresolved feasibility or contract sufficiency rather than demonstrated synergy. [Library interface](outputs/S1-r1-P04-A.json), [kit interface](outputs/S2-r1-P04-A.json). Prepare baseline, each parent, hybrid and a link-breaking or explicit additive comparison under the same requirements.

**P05:** Six coded books could move twice while their old paper addresses retain forwarding pointers. An unchanged starting index reaches the latest coded book through an intact route; missing pointers and cycles must return unresolved. Both reviewers qualified this raw capability/probe and confirmed a distinct family. The summary retained the route, but one reviewer found the household-label-mismatch challenge missing; normalized retention is uncertain, so retained exclusivity is not credited. [Raw A1](outputs/S1-r1-P05-A.json), [compressed D2](outputs/S1-r1-P05-D.json), [locked assessment](reports/main-S1-resolved.json). Prepare enabling dependencies and preserve every decision-changing challenge when compressing.

**P06:** A staging map assigns a labelled place to every required piece. Empty places expose incomplete picking; pieces left after filling expose incomplete transfer. This relocates tracking into an artifact, but overlap with other kit mechanisms and time/space requirements remained uncertain. [Carrier-transfer raw](outputs/S2-r1-P06-A.json). **P07:** The fast unshelved cart stays visible while address reliability and search-set density make different predictions. Matching size/count versus matching address accuracy can distinguish them. ## P08 — Keep Robot Talks disagreement productive

Both convergence methods used identical fixed concern reports. All four pairs received complete dual coverage. Delayed consensus added a distinct failure-stage question in both kit repetitions after scalar adjudication: **is an item already missing after picking, or does it disappear during filling?** Comparing picked contents with filled contents can redirect attention between access and transfer. The consensus probes did not explicitly observe that transition.

Both arms had decision-relevant competing predictions in every pair. However, every arm's probe feasibility and fit remained uncertain. Five scalar differences remained unresolved, including differing ways to count outstanding tensions. Consequently, **neither method produced a fully qualified probe under the frozen rules: 0/4 versus 0/4**. The added transition observation supports a sharper question, not a proven Robot Talks benefit or a feasible production improvement. [Resolved P08](reports/p08-resolved.json), [bounded adjudication](reviews/p08-adjudication.json), [kit P08 output](outputs/S2-r2-tension-P08.json).

## Compositions to investigate next

These are prospective designs; this run isolated stages and did not test their combined effects.

1. **Inversion → attack-to-expand → disturbance conversion:** preserve a reliable joint, challenge dependence on striking, and explore whether load can move an interface that increases grip. Specify geometry, load direction, material feasibility, the ordinary fastening rival and a slip/failure test. This is an untested hammer-design stimulus.
2. **Two lanes → mechanism interaction → Robot Talks:** one lane develops the incumbent; the other changes the interface between two partial mechanisms. Independent concerns produce opposed predictions. Compare ordinary, each intervention alone and their combination before crediting any combined gain.
3. **Generation → source-bound Distill → alternative slot:** protect a genuinely distinct raw relation and its full defeat conditions, then ask whether compression and recommendation preserve/expose it. Evaluate preservation and visibility separately from invention; the seven P09 additions make this boundary material.

For each next strategy, fill an outcome/evidence/attack/construction/rival/defeat/fit/lineage card, freeze a matched comparator and ordinary-family archive, and permit “no useful opening.” A feasibility-first probe should be informative within the actual resources; a stop rule alone does not demonstrate that it can deliver such evidence.

# Preparing novelty in the analysis process

Start with a preserved outcome, not a preferred tool. For the hammer example, the outcome might be a reliable joint; that does not yet prescribe striking, penetrating or permanent fastening.

The smallest useful novelty proposal contains **a changed causal relation, a construction, a rival prediction and an observation that could defeat it**. A new name or memorable sentence does not meet that standard. An unfamiliar possibility may already be well known elsewhere; this investigation measures distinction from the supplied case baseline.

## Ten prepared interventions

| Strategy | Preparation move | What must appear in the output |
|---|---|---|
| P01 — Invert the causal arrow | Ask whether the tool or its surrounding process creates part of the demand it satisfies. | A feedback path, a changeable link and a different prediction when that link is changed while preserving the outcome. |
| P02 — Attack to expand | Attack a necessary-looking dependency, then construct a replacement, remove the dependency or design a test. | Each attack linked to a constructive branch or an honest explanation of why no viable branch exists. |
| P03 — Convert the disturbance | Ask how a defect could become information, energy or a control input. | Input → conversion → response, including false responses and a breakdown condition. |
| P04 — Make mechanisms interact | Choose two existing partial mechanisms and change the interface between them. | Baseline, each parent and hybrid predictions under identical requirements; a test distinguishing interaction from their separate benefits. |
| P05 — Work backwards from a surprising capability | Describe the desired capability before selecting available tools; expose its missing dependencies. | The smallest enabling experiment that can be performed with supplied resources. |
| P06 — Move the function | Ask whether a material, interface, artifact or environment could perform work currently assigned to a specialist. | A different function carrier, its causal path, maintenance burden and remaining human responsibility. |
| P07 — Protect the inconvenient observation | Keep an actual supplied anomaly visible and seek two explanations that also account for ordinary cases. | Rival mechanisms and one observation on which they disagree. |
| P08 — Keep disagreement productive | Have Robot Talks concerns disagree independently; write their predictions before reconciling them. | A decision-changing uncertainty and the smallest probe separating the predictions. |
| P09 — Compress the relation | Mark the operation, dependency, discriminator and caveat before Distill compresses an idea. | Exact raw-to-summary lineage, including lost, rejected or parked distinctions and retained uncertainty. |
| P10 — Give a qualified alternative a visible slot | Hold candidates and assessments fixed; compare the ordinary recommendation with a view exposing one distinct useful alternative. | Both views, unchanged first choice, entering/displaced scores, fallback reason and added text burden. |

## Compose them as experiments

**P01 → P02 → P03:** invert a dependency, attack it, then ask whether the exposed disturbance can perform useful work. A hypothetical hammer example is: “Must assembly energy come from striking?” → “What else could move the joint?” → “Could applied load move an interface that increases grip?” The final answer must include the geometry, a rival prediction and a slip/failure test. This is an untested design stimulus, not a demonstrated device.

**Two lanes → P04 → P08:** one lane develops the incumbent, another explores an interface between partial mechanisms. Robot Talks separates beneficiary, operating and evidence concerns. Their conflict becomes a comparison of predictions rather than a vote about which explanation sounds better.

**Generation → P09 → P10:** preserve the relation that makes a candidate distinct, then test whether the recommendation exposes it. “Load moves interface, interface changes grip” carries more evaluable meaning than the label “smart fastener.” Caveats about load direction and material feasibility must survive compression.

These compositions are hypotheses for subsequent combined tests. The current controlled design isolates their stages; multiplying standalone gains would not establish a combined effect.

## A strategy card to fill before each investigation

1. **Outcome:** what must remain valuable, and for whom?
2. **Evidence:** what is supplied, what is inferred and what is unknown?
3. **Attack:** which apparently necessary dependency can be challenged?
4. **Construction:** which mechanism, question or function carrier changes?
5. **Rival:** what would the nearest ordinary alternative predict?
6. **Defeat:** which observation would show this proposal is wrong or unhelpful?
7. **Fit:** which constraints and burdens does it preserve or expose?
8. **Lineage:** does the distinction survive compression and recommendation?

Compare the changed instruction with a matched ordinary instruction on identical case evidence. Generation also has a generic-creativity comparator; P03 has resistance-only, P04 has separate parent arms and P06 keeps the original carrier. P08–P10 use fixed inputs so preservation and visibility are separated from invention.

Freeze evidence, comparison archive, criteria and mechanics before scored outputs. Keep independent first saves, explicit no-opening outcomes and failed attempts. Review raw ideas before summaries; use two independent assessments and preserve unresolved disagreement. Dispatch Spec makes sources, roles, joins, failure handling and evidence artifacts explicit. Its validation establishes route structure.

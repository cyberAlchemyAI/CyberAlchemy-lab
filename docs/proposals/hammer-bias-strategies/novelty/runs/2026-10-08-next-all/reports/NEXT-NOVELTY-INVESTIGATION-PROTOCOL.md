# Preparing experiments that can create novelty

This is an unscored successor preparation note for the ten candidates in `NEXT-NOVELTY-STRATEGIES.md`. It does not change the current thirteen-study frozen schedule, rubric or judgments. These methods remain hypotheses about an analysis process.

The starting question is: **What can this process cause us to propose or test that ordinary analysis of the same evidence would miss?** A new sentence, another explanation of the same mechanism or consensus among agents does not answer it.

## Prepare a strategy before naming its techniques

1. Write the valued outcome independently of the tool. For the hammer problem, specify the required joint behavior and resource limits before mentioning nails or impact.
2. Name one dependency to change. Examples are force delivery, joint geometry, information handoff, disagreement resolution or the feedback path that creates future tool demand.
3. Write a candidate operation and its nearest ordinary rival. Both receive the same evidence, access and allowance.
4. Predict a differing observation from a single controlled intervention. A changed operation with identical predicted observations needs a better test or an explicit unresolved discriminator.
5. State a feasible defeat condition. An unavailable record, unprovided physical configuration or unexecuted simulation cannot become evidence by being proposed.
6. Freeze the raw proposals and independent assessments before summarization. Compare creation, preservation, cost and observed usefulness as separate outcomes.

## Three candidate experiments ready for specification

| Candidate | Opening | Matched comparison | Defeating observation |
| --- | --- | --- | --- |
| Logical inversion + demand removal | A tool may change specifications so that later work demands the same tool. Interrupt that return path while preserving the initial valued outcome. | Return-path intervention versus a sham, with initial demand, available resources and observation period fixed. Separately compare ordinary analysis and vocabulary-only inversion. | Tool dependence persists equally, or the apparent reduction comes from sacrificing the valued outcome or exporting work to someone else. |
| Destructive attack + construction relay | Remove a dependency in a model or supplied test representation. A fresh builder receives the surviving outcome, constraints and exact failure, then proposes a replacement or separating probe. | Constructive relay versus critique-only and an equally budgeted ordinary relay, using the same incumbent and evidence. | The builder merely restates the failure, changes an unapproved constraint or reconstructs the attacked dependency without acknowledging it. |
| Robot Talks + preserved disagreement + Distill residue | Two concern agents commit to incompatible predictions. A converger constructs a separating probe. Material rejected by compression becomes input to a fresh bounded question generator. | Deferred disagreement versus immediate consensus; residue-fed generation versus summary-fed generation. Match evidence, context allowance and generation budget within each comparison. | Predictions do not differ, the probe cannot separate them, or the residue produces only restatements and unsupported extensions. |

These are prepared questions, not evidence that inversion, attack, disagreement or residue produces more novelty.

## Use two lanes to preserve productive tension

The first lane tracks the outcome, feasibility and resources. The second changes dependencies and proposes interventions. The critic attacks a named dependency; the builder must leave a replacement, removal, test or explicit no-opening. Concern agents investigate distinct questions and retain incompatible predictions until a probe can separate them. Distill preserves the changed causal relation, rival, probe, defeat condition, uncertainty and lineage.

Dispatch Spec should bind the exact inputs and assigned roles, source boundaries, handoffs, branch conditions, call ceilings and review order. Its route check establishes structural readiness. Technique effectiveness needs the experiment's own evidence.

## Improvements suggested by the current pilot

The I05 workflow pilot contains an intact-interface opening with agreed newness, family confirmation and resource fit, but its support grade remains unresolved after the one permitted scalar review. The broken-interface opening assumes inspection of an absent record and has partial contract fulfillment. A generic proposal leaves final disturbance checks insufficiently separated from answer exposure. The mechanical interface proposals retain uncertain feasibility. These are bounded model judgments, not measured workflow or physical effects.

For a future rubric, define operational examples for support labels before scored generation. Separate source-supported premises, an untested mechanism and an observed comparative benefit. Keep the current unresolved labels intact. Declare what counts as available evidence, freeze every scored output before revealing answers, and specify the resources required by intact and broken conditions symmetrically. Retain a negative or unresolved result when no supplied test can distinguish the opening.

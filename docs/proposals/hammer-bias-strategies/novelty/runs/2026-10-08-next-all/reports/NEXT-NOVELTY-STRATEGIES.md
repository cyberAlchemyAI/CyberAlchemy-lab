# Preparing the next novelty investigations

These are ten unscored candidate strategies for future investigation. They extend the preparation vocabulary without changing the current frozen thirteen-study experiment. None has a demonstrated novelty advantage. The current evidence supports testing raw generation separately from faithful preservation; disagreement about causal families must remain visible.

Each strategy must create a new possible intervention, prediction or separating experiment. A renamed operation or unusual sentence is insufficient. Preserve the valued outcome and constraints, then compare with ordinary reasoning and generic creativity using the same supplied evidence and allowance. Archive awareness must be equal within a comparison.

| Candidate combination | Operation that creates an opening | What would make the investigation informative? |
| --- | --- | --- |
| 1. Tool deprivation + two lanes | Temporarily remove the preferred tool and its vocabulary. One lane preserves the outcome; the other reconstructs a feasible operation. | Compare with a vocabulary-only ban and ordinary reasoning. A changed mechanism or probe must survive when normal vocabulary returns. |
| 2. Logical inversion + boundary search | Ask where increasing use of the tool makes the outcome worse. Find a boundary, then design an intervention just across it. | Vary one predeclared condition at a time. Opposing predictions locate a dependency; a verbal contrapositive receives no credit. |
| 3. Attack + construction relay | A critic removes one dependency; a fresh builder receives the surviving outcome, constraints and attack, then creates a replacement or separating test. | Compare the relay with critique-only and an equal-budget ordinary relay using the same incumbent. Require an explicit construction link or no-opening. |
| 4. Robot Talks + disagreement escrow | Concern agents commit to conflicting predictions. Keep the disagreement open until another agent proposes a probe that can separate them. | Compare with immediate consensus on identical concern reports. Agreement counts only as agreement; a useful new probe is a separate result. |
| 5. Distill + residue resurrection | Save the material that resists compression, including parked hypotheses and awkward conditions. Give a fresh generator that residue as a question source. | Compare residue-fed generation with summary-fed generation under matched context and allowance. Preserve lineage and judge new proposals independently. |
| 6. Carrier migration + constructive attack | Move the function from the familiar tool into an arrangement, material, actor or environment; attack the new dependency immediately. | Hold the outcome fixed. Account for displaced work and test whether the new carrier still works when its key dependency is removed. |
| 7. Protected anomaly + competing explanations | Make an inconvenient observation compulsory input to two different causal accounts; require opposite predictions from one intervention. | Compare with an equal-evidence process that may summarize the anomaly normally. An extra explanation without a separating prediction is insufficient. |
| 8. Backcasting + rival futures | Construct two futures that achieve the same outcome through incompatible dependencies. Work backward to the first intervention that separates their paths. | Compare with one preferred future and generic creativity. A resource-bound first step plus a defeat condition is required. |
| 9. Mechanism collision + interface ablation | Connect two useful mechanisms at their point of conflict, then ask whether the conflict creates a signal or capability. | Compare intact coupling, co-presence and a broken interface while preserving each parent. Test false signals and cancellation. |
| 10. Feedback inversion + demand removal | Identify how the tool's use changes specifications, habits or interfaces so that future work needs the same tool. Interrupt that return path. | Hold initial demand equal and compare return-link removal with a sham. Separate immediate performance from predicted future tool demand. |

Prepare each candidate with the same short card:

> Preserve **outcome**. Alter **dependency or operation**. Our opening predicts **X**; the nearest ordinary explanation predicts **Y**. Use **available resources** to run **one separating probe**. Reject or revise the opening if **defeat condition** occurs.

Use two lanes with distinct responsibilities: outcome and feasibility in one; changed dependencies and proposed probes in the other. Concern agents should investigate different questions. The converger selects a separating experiment while preserving unresolved alternatives. Distill protects the causal relation, probe, defeat condition, uncertainty and source lineage.

Save two independent raw assessments before compression. Score retention afterward; summary-only ideas are new proposals, with zero preservation credit. If a strategy merely produces more discussion, more options from the same causal family or more confident wording, retain that negative result.

Dispatch preparation should state inputs, assigned roles, source boundaries, branch conditions, review order, call ceilings and the exact evidence required at each handoff. The sibling Dispatch Spec checks route structure; execution admission and technique effectiveness require their own evidence. These ten candidates have not been added to the current run schedule.

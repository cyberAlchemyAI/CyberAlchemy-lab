# Prepared investigations: rereading and new-player return

**Date:** 11 October 2026. **Status:** design preparation, not a frozen or executed protocol. All counts below are proposed conditions or observations, not collected data. Participant recruitment, sample size, validated instruments, playable implementations and allocation remain outstanding.

## 1. Research questions and estimands

1. Does a specified interpretive feature change appreciation between first and second encounters with the same material?
2. Does a specified rule relation improve voluntary return compared with familiar relations or surface refresh under comparable access and rewards?
3. Does rhetorical delivery contribute beyond identical literal information?
4. Can a familiar completed experience produce satisfaction or delayed value without continued use?

Each intervention would estimate a bounded condition effect. A measured association between reported discovery and return would not establish that discovery mediates the effect causally. Condition differences can also change difficulty, autonomy or competence. Record these alternatives instead of naming every improvement a novelty effect.

## 2. Literary comparison

**Starting cards:** LL02, LL03, LL04 and LL05. **Methodological basis:** [Dixon et al., LS03](https://sites.ualberta.ca/~dmiall/LiteraryReading/Readings/Dixon%20Bortolussi%20Twilley%20and%20Leung.pdf); contrasting spoiler findings LS08–LS09.

Choose one rights-cleared passage or short story, a bounded feature and a justified alteration. A candidate is an ambiguity that permits two evidence-backed interpretations. An edited version should retain events and broadly comparable length/comprehensibility while changing the specified feature. Editors must document unintended changes.

Randomly assign fresh readers to original or altered text; both groups read twice with the same interval. Record prior familiarity and reading experience before allocation. An optional separate foreknowledge study randomizes a truthful ending disclosure versus a neutral introduction. Do not conflate that with rereading: disclosure adds information without another exposure to the whole text.

Collect enjoyment, perceived quality, recommendation, understanding and written interpretation after both readings. Score evidence-supported changes separately from rating increases. Independent graders should use a frozen rubric, be unaware of condition where feasible, and report disagreement. Add a delayed opportunity to choose the text again to distinguish prompted repetition from voluntary return.

**Primary outcome to freeze:** between-condition difference in a named appreciation change score. **Secondary:** supported interpretation changes and optional delayed selection. A rating scale and scoring rule must be selected prospectively; no validated new scale is claimed here. Check ceiling effects and comprehension changes.

One selected story cannot establish a theory of classics. Follow-up texts should vary the suspected feature and include less-canonized material selected independently of its response scores. Historical transmission requires its own corpus/exposure study under LL10–LL11.

## 3. Game comparison

**Starting cards:** LL07, LL08, LL09 and LL12. **Concrete material:** LG02 or LG03, after an implementation proves that conditions have viable choices in both modes.

Prepare three initial conditions:

| Condition | Purpose | Required implementation |
|---|---|---|
| G0 Familiar relation | Baseline continued mastery | The same core combat and a conventional, explicit objective. |
| G1 Surface refresh | Test freshness without the target relation | Comparable core rules with changed visual/content presentation. |
| G2 Changed relation | Test the proposed purposeful connection | The specified delivery/destination or survival/supply relation, with disclosed rules and usable actions. |

This is a proposal for three packages, not a claim that novelty alone can be varied. G2 can alter agency and difficulty. Preserve run length, item budget, feedback quality, reward schedule, platform performance and access; measure residual differences. Include a competent ordinary equivalent of the candidate relation where feasible. If such an equivalent reproduces the mechanics, compare experience claims separately.

Within a later LG03 study, compare ironic and literal descriptions containing the same facts, with identical rules and feedback timing. Keep this separate from adding/removing the supply relation. Otherwise rhetoric is confounded with the mechanical tradeoff.

**Population:** genuinely new players to the tested implementation. Measure genre familiarity and available time. Let players choose manual/autoplay and a hero before randomizing within those strata, so those choices do not respond to the experimental condition. This supports within-mode condition effects; self-selected mode or hero differences are not causal mode/hero effects.

Use the same observation window and equal optional opportunities to return. Apply intended condition assignment in primary analyses, reporting nonuse, missing data and crossover. Do not analyze only those who reach boss three as if they were the original randomized population.

## 4. Candidate measures with literal definitions

| Measure | Proposed definition | Interpretive limit |
|---|---|---|
| Initial attraction | Choice to start after a standardized description, before gameplay | Recruitment or presentation can drive it. |
| Seven-day voluntary return, candidate primary | At least one optional new session starting 24–192 hours after the first session starts | This is a broad return window, not exact D7 retention. Study-required visits are excluded. |
| Exact D1/D7/D30, secondary | Optional session starts in [24,48), [168,192), [720,744) hours from first-session start | Only cohorts with the relevant full observation window enter that metric's eligible denominator; report missing observation separately. |
| Run completion | Defeat all three bosses under the defined rules | Completion is achievement, not proof of future return. |
| Satisfaction at stopping | Fixed questions about enjoyment, resolution and why the player stopped | Absence of an answer is missing data, not dissatisfaction. |
| Meaningful discovery | Player states a previously unrecognized relation, cites an event and uses it in a viable plan | Novel claims and valid plans need independent scoring. |
| Mastery | Performance change on a fixed familiar challenge with equivalent resources | Practice or easier conditions may explain improvement. |
| Transfer | Solve a separately specified unfamiliar challenge using the relevant relation | New items, hints and difficulty must be disclosed. |
| Active playtime | Time with the game active and gameplay input/activity, under a frozen idle rule | More time can indicate friction rather than value. |
| Provisional inactivity | First reaching 14 consecutive observed days without a session, a candidate operational event | Not proof of permanent churn; later return is recorded. |
| Delayed value | Recall, reflection and optional recommendation at a fixed follow-up | Social presentation and self-report affect the measure. |

Session boundaries and idle thresholds still need implementation-specific definitions. Exact D30 requires at least 31 elapsed days of follow-up from the time origin. Choosing 14 days of inactivity is a proposed convention, not a validated industry threshold. Report sensitivity to other prospectively chosen thresholds.

The analytics method paper separates duration variables and explains incomplete observations. [Viljanen et al., LS12](https://arxiv.org/abs/1701.02359). For this proposed study, still-active players at the observation boundary are censored for the relevant duration outcome, not assumed abandoned. Satisfied completion and inactivity are different events: analyze completion, later return and noncompletion departure separately, or use an appropriate competing-event model. Do not silently treat completion as independent censoring in a churn comparison. No survival curve or lifetime estimate has been calculated.

## 5. Evidence that would support or defeat the proposed direction

Support requires an actual condition difference on a frozen outcome, meaningful discoveries or capability changes, and a plausible account of alternative explanations. An early novelty spike without later return would support attraction more than persistence. A familiar condition with strong mastery and equal return would weaken a necessity claim for novelty. A satisfied finish without return could support a successful bounded experience.

A rhetorical improvement must survive a same-information literal control. A rule-generation claim must survive ordinary-equivalence analysis. A creativity-learning claim needs retained unaided performance and transfer, rather than a single assisted plan. These are different claims with different tests.

## 6. What remains before execution

- Select material and freeze the exact feature, rule and ordinary equivalent.
- Implement public state, legal actions, event ordering and comparable manual/autoplay conditions; establish viable strategies and check difficulty.
- Choose primary outcome, instruments, scoring rubric, analysis, missing-data policy and observation windows prospectively.
- Determine sample size from a meaningful effect and variance/pilot information; do not invent power from absent data.
- Prepare participant information and recruitment appropriate to the actual study, then run and preserve results under a separate execution record.

The LL cards can guide those preparations now. This document does not authorize or report recruitment, deployment, automated playtests or a new agent study. Earlier human authorization for the closed Robot Talks/Deep study is preserved with that study's records.

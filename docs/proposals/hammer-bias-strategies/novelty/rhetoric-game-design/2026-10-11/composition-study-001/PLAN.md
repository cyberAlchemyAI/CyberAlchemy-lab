## Objective and discovery baseline

User objective: try the saved strategies in different combinations with Robot Talks and Distill, generate more unexpected game mechanics, and compare them with existing games to identify defensible novelty.

The user's original concern supplies the assumption to challenge: a tool can make every problem look like its own target. The later objection that the output was merely analysis supplies the central misalignment: unusual wording and familiar effects may be mistaken for a new mechanic. Additional assumptions to inspect are that combining methods adds a decision beyond their components, and that distillation can preserve an unusual dependency rather than erase it. These are operational interpretations for the user to evaluate at the Robot Talks setup gate.

Inputs: the saved MG01–MG16 catalog, MC01–MC04 examples, WM01–WM24 portfolio, game specification, seventeen-game precedent map and the current user objective. The existing sources and prior six design-role turns are historical evidence, with their own scope.

Fixed frame: choose one character from three; three stages with a boss in each; mid-stage acquisitions; demanding manual execution or player-authored autoplay. Generate paper rule proposals, not a game implementation. Alternatives that change this frame must be labeled separately.

## Proposed Robot Talks concern decomposition

1. **Rules and simulation:** Do each candidate's events, costs and state transitions admit coherent execution? Excludes controller usability, experience judgment and market novelty.
2. **Control and authorship:** Can a manual player and a bounded authored policy express the promised choice using public information? Excludes physical-rule repair, enjoyment inference and market novelty.
3. **Player interpretation and experience:** Can the unusual causal relationship be learned from feedback, and does the promised surprise survive explanation? Excludes implementation decisions, controller implementation and global originality.

The parent owns source research, cross-layer synthesis, gates, reconciliation and novelty judgments. Agents inspect independently and write separate reports; evidence overlap is permitted, question overlap is not.

Alternative considered: one investigator per composition. Rejected because six isolated mini-design reviews would hide common conflicts between simulation, policy and meaning. The chosen concern split tests the same six proposals across distinct layers. A single investigator would have to trade depth for coverage. Early discovery is worthwhile because an unexamined contradiction could invalidate several candidate designs; this is an audit, without implementation.

**Setup gate:** pending user evaluation of the central question, assumptions and concern decomposition. Robot Talks agents do not start before approval. Independent generator construction, Distill work before the audit and prior-art research may proceed under the explicit objective.

Each Robot Talks report must use Key Findings (3–5 evidence-backed bullets), Gaps or Inconsistencies, Local Tensions and Questions for Synthesis. Cross-layer synthesis names what each layer holds, impact, evidence and proposed disposition. Its human gate records accepted, deferred, uncertain or rejected tensions before actions based on that synthesis. Implementation is outside scope.

## Evidence, comparison and claim boundaries

For each retained candidate, inspect official game descriptions, developer explanations or primary manuals by operation and synonyms, including older and out-of-genre precedents. Record URLs, inspected passages/access depth, positive overlap, exact proposed differences and unknowns. Do not infer a feature's absence from marketing silence. Unexpected to this design discussion, distinct from the supplied prior portfolio, different from an inspected precedent and globally original are separate claims.

Use these final labels: known mechanic; familiar ingredients with an identifiable new arrangement; distinctive candidate relative to the inspected set; insufficient evidence. A worldwide first cannot be earned by a finite web search. A game resemblance is not itself a reason to discard a useful mechanic.

The final report will include the eighteen-draft pool, six developed candidates and reserves/rejections; actual role receipts and changes; Robot Talks tension synthesis and gate state; Distill closure, technique trace and cycle guard; candidate-by-game comparisons and a novelty ledger; local artifact validation and a requirement-by-requirement completion audit.

Stop each Distill composition after three rounds, or earlier if a responsible closure/cycle guard applies and the stopped-round reason is recorded. Preserve stable disagreement. No new global skills, implementation, publication or earlier experiment edits are authorized by this study.

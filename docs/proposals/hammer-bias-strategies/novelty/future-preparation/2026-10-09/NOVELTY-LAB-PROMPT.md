# A prompt for creating a new next move

This is a reusable preparation prompt for the ten strategy cards. It is unrun, grants no experimental credit, and does not replace the frozen prompts or comparisons of the existing thirteen studies. An investigation using this kit still needs its own case packets, archive, literal stage prompts, schedule, budgets and execution admission.

## Supply the task

Fill in the valued outcome, hard constraints, actual observations, available resources, ordinary solutions already considered, and the dependency associated with the preferred tool. Give every observation and ordinary solution a source ID. Unknown resources remain explicit assumptions.

For the hammer example, identify the actual function: joining, positioning, releasing, signalling or something else. A different function changes the task and needs a separate variant.

## Ready-to-use instruction

> Create a new operation, question or experiment from the supplied problem. Maintain two lanes. The outcome lane preserves the valued outcome, hard constraints and burden on each actor. The invention lane mutates a dependency, causal arrow, carrier, sequence or interaction and records what becomes possible.
>
> Choose one of the ten mutations below. Name the assumption it changes and cite the supplied facts that make the change worth investigating. Produce a concrete construction, with an explicit action and predicted consequence.
>
> Use Robot Talks to retain the strongest disagreement: one account supports the construction, another offers its closest ordinary rival. Each account must predict an observable result under the same proposed intervention. Preserve incompatible predictions until they can help design a separating probe.
>
> For destructive-to-creative work, the attacker passes one broken dependency, the surviving outcome, and the specific failure to a fresh builder. The builder returns a replacement, a removed requirement consistent with the outcome, a separating experiment, or an explicit no-opening. Record any dependency it reintroduces.
>
> Use Distill to produce both a compact core and source-bound residue: omitted conditions, rejected branches, incompatible predictions and unresolved resource assumptions. A fresh builder can receive either artifact according to a declared comparison. Any idea created by an editor is a separate proposal requiring assessment.
>
> Return an anchor, mutation, construction, rival, probe, defeat condition and residue. Then write one memorable sentence naming the changed operation. Keep unknowns attached to the proposal. A feasible probe requires available indispensable resources; otherwise return a resource-acquisition step and a conditional hypothesis.

## Ten starting moves

| Mutation | Start here | Required construction |
| --- | --- | --- |
| Tool deprivation | The hammer disappears; the outcome survives. | A way to preserve the function after removing its actual tool dependency. |
| Causal return-path inversion | The hammer teaches the world to grow nails. | An intervention on the hypothesized path from tool use to later demand. |
| Attack to expansion | Break the assumption; hand the opening to a builder. | A replacement, removal or probe derived from the named failure. |
| Carrier migration | Let the joint inherit the hammer's job. | Transfer the function to the object, arrangement or environment, with displaced work accounted for. |
| Deferred convergence | Let the disagreement design the experiment. | A probe on which two live accounts predict different outcomes. |
| Residue-fed construction | The discarded footnote gets the next experiment. | A new next move derived from omitted material, with its source and uncertainty retained. |
| Protected anomaly | Give the awkward fact a vote. | An intervention that differentiates two accounts of the inconvenient observation. |
| Rival backcasting | Two successful futures enter; find where their paths split. | The earliest feasible present action that distinguishes their dependencies. |
| Interface ablation | Keep both tools; interrupt their conversation. | An interaction-dependent operation, challenged by preserving both parents while breaking their link. |
| Objective boundary inversion | Find where more solution creates more problem. | A predeclared boundary probe or operation that avoids the harmful regime. |

Logical necessity and causal inversion need different tests. To challenge the hammer's necessity, construct the valued outcome without its dependency. To invert a causal arrow, treat the reverse arrow as a hypothesis and specify an intervention that could defeat it. Sentence reversal alone establishes neither.

## Decide whether the process added useful novelty

Assess the raw construction against the supplied ordinary archive and concurrent controls. Require a different operation or discriminating prediction, resource fit and a clear defeat condition. Judge preservation, new creation and display separately. Retain equivalence and feasibility disagreements as unknown.

The prepared four-cell comparison crosses immediate/delayed convergence with summary/residue input to a fresh builder, with ordinary and generic relays.

# Technology component and binding preparation result

Status: **candidate project modeling; no vendor approval, component version selection, installation or deployment**.

The [two new local meanings](../../model/DEFINITIONS.md) distinguish a Technology Component candidate from an environment-specific Integration Binding. Each has a generated project-scoped Definition/v1 record and a separate [Artifact Type Request](../../model/carriers/README.md) with a closed schema. The requests compare Lab Tool/v1, Implementation/v1 and Decision/v2 by their validation purposes; neither local type is Lab-admitted. The ontology now proposes component-to-review and binding-to-component/review links without applying Lab graph relations.

The [catalog](../../model/integration/component-index.json) contains 24 source-bound candidate component identities for named packages, services, browser APIs and tools. Every record explicitly leaves its upstream identity, exact version, terms, legal processor and operating owner unresolved. Existing option reviews now reference component IDs. The [stack audit](../../model/integration/STACK-COVERAGE.md) distinguishes these named candidates from still unnamed API framework, driver, migration, local store, scoring provider, hosting, secrets and observability choices. The Integration Binding carrier has **zero instances** because no owner Decision or verified release configuration exists.

Current [coverage](../../model/carriers/coverage.json): 149 selected Lab carrier candidate records, 154 local candidate records, 18 Artifact Type Requests and 15 explicit gaps. [AT-G15](../../model/carriers/gaps.json) tracks version, license, processor, operating and binding work. A [fresh exact Lab review cut](../../../CyberAlchemy-lab/docs/proposals/engineer-assessment-research/2026-10-26/technology-components-v1/manifest.json) pins the model and selected Lab schema/registry evidence. Structural and source parity checks passed; they do not establish current package fitness, license entitlement or approval for participant data.

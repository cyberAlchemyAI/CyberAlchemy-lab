## Implementation detail: ordered rules

1. Declare question and falsifier/method before run
2. Resolve allowed experiment context and relations
3. Execute bounded selected procedure
4. Capture measurement provenance and exclusions
5. Assess inconclusive/negative/positive evidence without equating run to confirmation
6. Propose selected results

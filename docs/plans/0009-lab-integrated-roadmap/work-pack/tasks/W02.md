## Implementation detail: ordered rules

1. Resolve actor and exact current authority references
2. Check scope/action/period/revocation/redelegation/gates at dispatch
3. Reject unknown, denied or expired authority before tool execution
4. Dispatch only selected bounded local adapter
5. Capture inputs/output/receipt/residue
6. Reconcile indeterminate non-idempotent actions before retry

## Edge cases and failure modes

- Admission interpreted as action grant
- Revocation after preparation
- Agent receives owner key
- Uncertain action retried twice
- Persistent Machine Agent identity

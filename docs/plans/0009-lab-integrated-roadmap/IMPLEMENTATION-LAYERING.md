# Implementation layering for the whole Lab

Status: proposed; authority effect: none. Source: [roadmap](../../ROADMAP.md) and [milestone analysis](ANALYSIS.md).

| Layer | Decision question | Minimum useful unit | Exit / join | Main cost and deferral |
| --- | --- | --- | --- | --- |
| L0 | After this layer, we know whether exact authority/state/context support a bounded transaction. | Existing admitted v1/D74 proof; repository D75 distinguished. | B00 scoped evidence, B01 current reconciliation. | Contract/source alignment; real permanent operation deferred. |
| L1 | After this layer, we know whether real operation continues across admissions without rebuilding the executable. | Real Work, reviewed profile transition, restart and new session. | C13 after exact successor review and explicit provisioning. | Profile/promotion/replay evidence; broad workflows and services deferred. |
| L2 | After this layer, we know whether contracts support useful work and assessed operational learning. | Engineering + research and later lesson application. | W09 after exact workflow review and real cases. | Domain/authority/failure/lesson integration; exhaustive autonomy deferred. |
| L3 | After this layer, we know whether a declared Lab domain is coherent across source, authority, ontology and implementation. | Selected mapped/migrated slice with challenge joins and rebuild. | O07 after selected mapping/import review. | Semantic adapters/source reconciliation; unselected sources/retirement deferred. |
| L4 | After this layer, we know whether the bounded Lab Product is useful and operable enough for stable v1.0.0. | Reproducible selected interface/install and real pilot. | R08 exact owner release decision following R07 evidence. | Product/packaging/pilot/release evidence; unselected multi-host/services/frontends deferred. |

Value = decision unlocked + user outcome + risk reduced. Cost = implementation + verification + coordination. Stop adding work to a layer when its next unit contributes less value to that layer's decision than advancing the next bounded decision. No dates or duration-based critical path are asserted.

All layers preserve exact authority, immutable history, closed typed endpoints/qualifiers, independent semantic/governance streams, ephemeral Machine Agents, session-only short memory and derived-view non-authority. Candidate review, implementation admission, binding/adoption, action permission, runtime observation and Product value retain separate claims.

Ontology mapping and Product acceptance design may start after B01. Their early design does not declare L3/L4 complete. Milestone joins require earlier operational evidence. Recommended next layer: L1, task C01.

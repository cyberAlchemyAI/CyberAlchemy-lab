## New implementation

API44 is a frozen candidate successor for classification and failure preparation.
Its calculation follows this order:

1. Authenticate and check the exact request; inspect the durable operation key.
2. Claim a new key outside the pure calculation scope.
3. Run full original source and producer checks before borrowing sealed facts.
4. Validate prospective schemas and Decision cores, then calculate the domain
   result. Every policy check still reads its actual policy and real clock.
5. Stage exact evidence bytes in a bounded temporary buffer. No evidence objects
   are written during this calculation.
6. Run full original source and actual policy exit checks. Any failure discards
   the unpublished buffer and prevents return of a candidate result.
7. Publish evidence outside the pure scope, using the original immutable vault
   writer, then finish the original journal and check delivery deadlines.

The buffer preserves original bytes and content hashes. It limits individual
objects to 1 MiB, aggregate temporary output to 64 MiB and distinct objects to 256.
It contains calculation output; it supplies no Agent identity, Session memory,
permission, semantic owner verdict or admission.

An interrupted publication may leave immutable evidence objects and a pending
operation claim. The existing inspection/recovery rules still apply; this change
does not promise rollback or authorize redispatch.

Calls and replies retain their original public envelope/profile fields. Caller JSON cannot choose a profile, store, policy, signer, owner roster, or publisher. A shared profile does not itself qualify all declared operations.

It routes the three owned governance operations, and `operation.inspect` lookups naming those operations, to the governance branch. Other calls reach the existing dispatcher unchanged.

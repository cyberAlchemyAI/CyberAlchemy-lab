# Selected R02 packaging successor

## Selection and authority

This successor preserves the frozen predecessor and selects revised byte postimages for its installer, source context description and operations runbook. It closes the documented historical Session privacy boundary and requires privately owned candidate destination parents. No canonical owner outcome, activation, publication or stable release is asserted.

## Executable package and source repository

The package contains 87 selected foundation runtime/profile/schema/control source files and eight exact dependency wheels. It excludes admitted artifact bodies and baseline source snapshots. The independently pinned source repository stays separate as local project state; actual replay and profile capture read it explicitly. All selected source and epoch files are bound by the source manifest before and after effects. The original frozen D74/D75 profile hashes remain unchanged.

The supported environment is the exact CPython interpreter digest, Python and SQLite versions, Linux x86_64 and libc tuple. Installation extracts selected wheel bytes directly, rejects wheel hooks and collisions, and uses `-I -S` to load those dependencies. Global site packages and runtime network dependency resolution are absent. This is foundation packaging; the eventual complete 34-operation Product API payload remains an R03/S02 obligation.

## Installation and local transaction boundaries

A trusted development adapter supplies the exact privately owned candidate parent. New destinations receive only exact code, profile/schema/control and dependency bytes. Linux atomic no-replace publication protects existing directories; exact retry verifies the entire file closure. Incomplete stages and foreign destinations are retained and rejected. Installation creates no store, key or action authority. The cooperative parent lock serializes installers within the owned scope.

Upgrade uses independently pinned full parent replay and the existing C05 reviewed D74→D75 carry/exclude protocol. Its actual new signature authorizes only a candidate reconstruction. Original signed parent history is preserved. Parent admission is never transferred to the new branch. Fault injection, native no-replace checks, replay and stale signatures remain covered by the selected-environment C05 suite.

## Public export and protected recovery

Public branch evidence export excludes the exact baseline. It retains the selected committed transaction evidence, HEAD and profile/plan references, rejects private keys and actual short memory, and verifies the cut again. It is not a standalone replay archive; its omitted baseline remains an explicit dependency. Source schemas may declare memory fields; those declarations are distinct from actual Session memory values.

Protected local history archives retain the complete independently verified committed branch, including the original baseline and its historical admitted Session records. They exclude uncommitted Session notes, private keys and caches. These archives remain mode 0600 inside privately owned temporary state and are removed after proof. They are never added to the distributable package or public proof receipt. Archive digests, file digests and public replay pins are evidence only.

Protected restore verifies the independent archive digest and original byte hashes, performs full signature/schema/cut replay before publication, rejects unselected files, and publishes without replacement. Interrupted durable stages can resume. Historical Session records remain archived project provenance; no active Agent Session, short memory or derived cache is rehydrated. Genuine Agent continuity still comes from bounded Project State, Context View and Ontology View.

Rollback selects retained old code/dependencies and its old branch using original independent pins. It verifies them and preserves the successor. Missing rollback dependencies block selection. No branch HEAD is rewound, no signed history is deleted and no permanent runtime pointer is activated.

## Evidence ceiling

The receipt proves isolated candidate packaging and recovery on the exact selected local environment. Human Product journeys, all Product operations, final owner/registry/profile/postimage closure and actual admitted operation/release remain S02/R08/A01-A04.

# Composite installation environment selector

This separately versioned T09 candidate binds the whole unchanged original
API16 composite descriptor and historical disclosure/classification document.
It does not compare that whole descriptor with the smaller R02 environment.
The closed `lab-R02-composite-subdocument-selection/v1-candidate` selects exactly
`/R02_environment`; all seven original fields and exact values remain required.
The original R02 package, environment guard, wheel validation, installed byte
closure, owned root checks and no-replace installer execute unchanged.

`supported-composite-environment.json` uses the new closed composite v3 schema.
The selected T07 v2 current public execution closure is separate from original
historical provenance: 720 public inputs, the complete recursive ELF graph and
wheel contents, copied stdlib/SQLite, native executable and every installed ABI
library. The native/ABI requirements must exactly equal all applicable rows in
the independently pinned dependency selection. Each current input is checked
through original T07 preflight and the complete installed file/mode/hash guard;
matching R02 alone cannot waive a composite requirement. Unknown fields, omitted
requirements, incompatible environment/configuration and altered native bytes
refuse before installation publication.

The successor binds the whole original composite documents by fixed original
path/hash, their complete 24,497 source and 24,496 profile row tables unchanged,
and the original private/protected classification document. It reads those
public descriptors, not the protected bodies referenced by classification rows.
No private key, old grant, live database or original operator state is installed
or copied. A new supported native locator is explicitly selected from T07's
independently staged identical bytes; the missing original native locator stays
in original provenance and is never recreated or treated as an identity alias.

Focused execution proves current public environment and technical package
installation only. `require_full_original_proof()` invokes the actual unchanged
original API16 full guard, without catching its failure, dropping its rows or
substituting a smaller guard. Original unavailable paths retain their refusal.
The candidate never returns full-original-proof qualification. API17 has no
selected final shared manifest at this stage; T08/shared dependency acceptance,
final composite/shared qualification and T15 onward remain closure prerequisites.

`CompositeEnvironment.transition` is a trusted mechanical installer adapter,
not a public authorization API. The coordinator supplies independently selected
descriptor/package pins, exact owned scope and active preimage after existing
private custody, real deadline, source, permission and approval checks. This
candidate grants none of those permissions and starts no service. The original
`InstallationRelease` private policy/source/schema/clock locks remain required
in a successor public integration; existing public handlers are unchanged.

Installation receipts bind the exact composite digest, R02 subdocument, selected
dependency/native/ABI requirements and actual original-byte installation result.
Receipts stay beside generations, so the original installed closure is unchanged.
The active descriptor carries the same environment selection. Upgrade verifies
the exact retained predecessor/package bytes and requires that environment;
rollback verifies the retained generation and its independently selected receipt
before activation of its local descriptor. Different environments, changed
preimages, collisions and corrupt retained bytes refuse. Previous generations
are retained; no Session, service or canonical release is activated or restored.
Failures after staging retain owned outputs and require reconciliation; no
automatic retry or deletion is implemented by this adapter.

The focused harness runs from T07's root0004 local loader and libraries with
cache disabled, no inherited ambient environment and Python `-I -X utf8 -B -S`.
Standard `importlib` imports the actual original `api-integration-v16` package
name and files; no file origin, runtime principal, guard or origin allocator is
overwritten. Original modules, current T07 code, runtime bytes and task inputs
are pinned before and after the run. All technical effects are under uniquely
owned mode0700 T09 roots. The harness exercises genuine installer calls and
actual byte corruption/refusal; it does not use mock installer success.

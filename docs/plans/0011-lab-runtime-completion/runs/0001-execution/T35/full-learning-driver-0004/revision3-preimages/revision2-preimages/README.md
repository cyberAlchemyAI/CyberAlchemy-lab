# T35 complete learning measurement successor

This is a separately selected qualification driver. No production API, Source,
Session, native reader, original callback, clock or period has changed. It is
not ready for an episode until Root independently includes every new origin in
an eligible complete source/profile/capture and selects exact input bindings.
The original provider and complete positive/security lifecycle bodies remain
unchanged. Their full apply, exact retry, inspection, assessment, attached close
and parent live-resource checks remain. Positives and negatives use separate
fresh episodes with the original real fixed deadlines.

The observer measures selected Python code starts and active nested segments
with monotonic elapsed and per-thread CPU. It records source pins, true code
paths, line and qualname, plus instruction-byte SHA only. It never reads frame
arguments, locals, return values, proof/key/note contents or exception messages.
This code metadata is attribution, not proof that mutable live constants or
callbacks equal source. Security/custody qualification remains independently
required. Stdlib/dependency/native child instructions are excluded. First
registration and pinned public-source capture overhead lies in the phase
elapsed envelope, before the first timed code segment. Generator suspension is
excluded; crossings, incomplete stacks and mismatches are explicit.

Original `fcntl.flock` calls are observed through events on selected code lines,
without a wrapper or inspecting descriptor/lock arguments. Acquisition and
unlock envelope timings include monitoring and cannot isolate pure kernel
wait. A same-code, same-thread, single-outstanding acquire-to-unlock interval is
reported only after a successful unlock; multiple outstanding locks are
ambiguous. Cross-function, externally acquired, non-flock/native locks and
unobservable instance identity remain gaps. There is no claim that every lock
wait or every native internal function is timed.

Per-phase `RUSAGE_CHILDREN` user/system deltas cover reaped descendants charged
during the interval. Running/unreaped children, other processes and per-child
instruction/identity attribution are unavailable. A child reaped in one phase
may have executed earlier; this is not exact execution-within-phase CPU. The
parent and measuring-thread CPU fields are distinct.

Runtime calls and caller classification/handling have separate phase events.
The fresh security adapter measures its existing negative construction/call
cost, and the unchanged security helper's foreign attachment negative gets an
exact selected-line span. All original security cases remain mandatory; these
measurement additions do not establish a full security suite or a realistic
positive margin when negatives consume a separate lease.

Default cProfile remains disabled. Monitoring still has overhead. Pure controls
run real inert fixed-workload trials with observation disabled/enabled, under
the selected installation0004. Those observations describe this own workload;
they are neither a protected-runtime calibration nor upper-bound estimates.
No predictive T03 margin thresholds or current empirical policy are invented.
The real failed episode81567 and its deadlines remain historical evidence.

The observer owns only its reserved monitoring tool, handles partial start
failures transactionally, serializes concurrent snapshots, preserves primary
callback failures across failed metadata/event recording, and labels capped
exception/lock observations. Such dropped/error observations fail driver
qualification. The retained managed original remains the only uncertain
journal evidence; no redundant copy/private body export was added.

Independent review, fresh source/profile capture, actual complete positive and
fresh negative episodes, child/native/lock limitations, empirical calibration
and T03 enforcement qualification remain required. Authority effect is none;
no dispatch, canonical admission, governing owner or whole task closure follows.

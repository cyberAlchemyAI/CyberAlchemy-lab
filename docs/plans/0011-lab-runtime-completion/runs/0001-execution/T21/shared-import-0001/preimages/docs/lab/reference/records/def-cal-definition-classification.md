# Classification

Assigns a particular thing and version to declared categories and values. Categorizing it does not change its identity or establish cause, success or authority.

**When it applies**

Classification is the governed act and result of assigning an exact subject revision to declared values under independently named axes in one exact Classification Scheme.

**Record formats**

**A stated exclusion**

Classification does not establish identity, Definition meaning, conformance, admission, authority, ownership, causality, realization, success, or ontology truth.

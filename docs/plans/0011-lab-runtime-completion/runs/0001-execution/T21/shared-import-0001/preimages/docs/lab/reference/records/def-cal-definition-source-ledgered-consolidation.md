# Source-Ledgered Consolidation

Combines dispersed work while recording each source group, its authority status and its review route. Synthesis and copying do not themselves grant authority.

**When it applies**

Use this term when CyberAlchemy v2 gathers material from inventory, ontology-vault, CyberAlchemy, Arcanum, framework-unification, DomainSpec, and validation sources. The consolidation should preserve source links, evidence confidence, commitment confidence, and owner routes.

**Record formats**

No record-type contract in this selected catalog declares this exact definition among the meanings it uses.

**A stated exclusion**

Admission, activation, publication, release, deployment, and external effects.

# Inspect what exists. Know its scope.

The site explains the Lab model and provides a selected source edition. The local operational foundation and the products being developed around it have different scopes.

<a id="available"></a>

<a id="available-title"></a>

## What exists today

The local Lab foundation records governed work and supports reconstruction of project knowledge. The [operational-scope chapter](guide/operational-scope.md#today) identifies its accepted foundation, proposed updates and outstanding release work.

This website is a static documentation edition. A stable installable Lab release, hosted service, automatic ontology coverage and operational Craft connector have not been established by this edition.

Craft is a separate software-design product under development for closed beta. Its [article](craft/model.md) explains the selected modeling and compiler scope.

## Review and contribute

For a documentation correction, identify the page and passage, explain the problem and include a concrete replacement or supporting source. Keep changes to accepted definitions on their declared review and admission route.

[Open the development repository](https://github.com/cyberAlchemyAI/CyberAlchemy-lab) to inspect the current tree and use its available contribution routes. The captured source links above provide the selected documentation edition here.

[Prepare a proposed definition](how-to/prepare-definition.md) or [send a downloaded reading-study response to the person who shared the site](research/reader-study.md).

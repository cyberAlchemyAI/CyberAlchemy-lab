Start with the admitted inspection path

For a first inspection, use the admitted local v1 executable and its frozen Decision 0074 source profile. Decision 0075 admits that exact executable for local inspection, authorized local transactions, replay/recovery and ephemeral context. The admission is an external overlay: its original README can still say candidate without undoing the later decision. Read the admission scope , then follow first inspection .

The three-command walkthrough checks public source files and selects a deliberately nonexistent store. It creates no store, key or transaction. Its observed output is D74 with 698 verified sources and 468 subjects. This is a useful working entrypoint; it is separate from a permanent service, a new installation and the expanded API.

What a result establishes

Record the selected executable/profile, source cut, current permission, exact input and observed output. Then read the result posture. A prepared candidate, an admitted record, an actual action and an assessed benefit are distinct facts.

The full integrated learning path is not yet a supported successful tutorial. The measured episode expired, and the later family4 build exposed a dependency cycle before final runtime qualification. Those failures remain in status and maintenance . This handbook preparation does not close T21 or publish a release.

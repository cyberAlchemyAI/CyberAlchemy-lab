Reference / Definitions / Context Map

Context Map

Owns the declared directional relationship between particular Bounded Context versions. Those contexts do not maintain rival copies of that relationship’s membership.

When it applies
Canonical endpoint membership and directional semantic or integration relationships between exact Bounded Context versions.
Record formats
Context map · v3
A stated exclusion
Directory trees, import graphs, runtime topology, and authority transfer.
Formal definition, source explanation and boundaries

The formal statement governs the meaning. The short introduction above helps you read it; it does not replace its requirements.

Source explanatory wording

The one authoritative record of which exact bounded-context versions participate in a relationship and how information moves between them. Contexts do not copy that membership back into themselves.

Exact governing statement

A Context Map is a versioned, owner-approved set of exact Bounded Context endpoints and typed directional relationships between them. The Context Map is the sole canonical owner of its endpoint membership and relationships. Each relationship declares source and target roles, integration or translation contracts, information and authority limits, owners, evidence, drift handling, and change coordination. Endpoint contexts do not canonically backreference the map; reverse membership is generated by indexing canonical Context Maps.

ContextMap = (id, version, context_refs, relationships, owner_refs, lifecycle, evidence_refs, drift_route); Relationship = (source_context_version, target_context_version, direction, relationship_kind, contract_refs, translation_refs, information_boundary, authority_boundary, owners); CanonicalOwner(context_refs,relationships) = ContextMap; ReverseMembershipIndex(c) = {m.id | c in m.context_refs}; Proximity does not imply Relationship.
  • Both endpoint identities and versions are explicit in the map.
  • Direction and authority limits cannot be inferred from imports.
  • One mapping pattern is selected by its owners, not by this generic definition.
  • An endpoint backreference cannot establish, amend, or revoke map membership.

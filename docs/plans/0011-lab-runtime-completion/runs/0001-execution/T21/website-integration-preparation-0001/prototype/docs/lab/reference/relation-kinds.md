# Declared relation kinds

<a id="catalog-relations"></a>

<a id="catalog-relations-title"></a>

### Connection rules · relation kinds

A relation kind defines one meaning of a connection and the permitted source–target kind pairs. A specific connection must also meet the rule’s version, scope and other requirements.

The profiled T35 run consumed its inherited Context deadline: Context was issued at 13:18:10 UTC with a 900-second bound ending at 13:33:10. Session opening returned only 349 seconds of that lifetime. This proposal does not renew that deadline or infer normal latency from cProfile.

The actual producer path remains material to the result. Session opening called `source/base.py:original` 302,875 times, with 268.58 profiled inclusive seconds, and `verify_source` 146 times. Context delivery called them 151,980 and 77 times respectively. Nested inclusive times cannot be added. Calls arrive through real permission/source guards, SignedSources guard, independently selected reader package/selection, source package verification, mapper preflight and Context preparation. Existing sealed fact scopes optimize EL calculations but retain these original full producer guards at their boundaries.

The first change preserves every verifier invocation and every byte hash. A fresh no-follow table scanner replaces repeated PurePosixPath/Path construction, ancestry `is_symlink` calls and full ignored byte-string allocation inside each complete table loop. It holds only directory descriptors and leaf identity metadata within that invocation. Single-record reads retain their exact returned bytes. Independent code and entry identities are selected outside the kernel; kernel callback changes, input changes, ancestor changes and exceptions prevent return and close all owned handles. Duplicate or alias locators are refused. Metadata row lists come from one independently pinned captured manifest rather than a second unbound read.

Write envelope: one new `source-input-capture-v1-completion-0001` component and five staged files under this run, mapping to diagnostic-0004 `source/base.py`, `reader/reader.py`, `mapped/base.py`, `context/base.py`, `context/generation.py`. The resulting true versioned Source callbacks and helper filenames must be independently eligible in the next source/profile before use.

Actual component evidence reads the entire existing 1,263-row source table; it does not execute a prospective family or Session. Warm original full guard and new table timings establish only a modest local improvement. Source and schema versions have not been optimized or suppressed. Live revocation/expiry, copied schema/profile/source tamper, original read-only effect rejection and full single-process lifetime are downstream qualification obligations for the actual new family. This component alone does not close T03.

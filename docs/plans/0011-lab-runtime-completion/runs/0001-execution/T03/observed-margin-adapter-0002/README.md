# T03 observed margin adapter successor

This is a staged successor correcting independent review MA01–MA03. Version1,
its full original preimages, review, failures and controls are preserved. No
shared API, current Source, helper family, period, lease or installed dependency
has changed. All reservations/calibration remain unknown; the enforced variant
refuses missing or mismatched empirical policy. Diagnostic mode remains an
explicit independently selected mode, with real original deadlines and no
margin success claim. Historical recorded/pending retries return before the
fresh gate, preserving original recovery and independent old outcome reads.

MA01 compares the original closed `{ref,sha256}` period binding with the
independently selected closed `{path,sha256}` binding after canonical locator
normalization. It retains the original policy schema and exact bytes/identity.

MA02 uses a separate captured helper graph seal. Root must supply `helper_capture`
to the new private `composition.compose`: an immutable tuple of four records
`(name, actual_captured_module, true_absolute_origin, expected_sha256,
verified_exact_source_bytes)`, for observed_margin, margin_capture,
margin_kernel and margin_seal. These come from an independently selected closed
startup capture; API payloads cannot supply them. Composition checks every
source-defined helper function/method against an independent compilation before
calling the seal factory. There is no helper-selected seed pin or default.

The guard holds callable code/default/closure/context objects and immutable
snapshots of helper namespace/constants, mutable defaults/closure containers,
relevant library aliases/descriptors and callable code. It includes CHECKPOINTS,
REMAINING, the capture helpers and guard helpers. The guard itself runs with an
isolated global context containing only explicitly held builtins; the original
Vault claim's added gate checks its held code/default/context before execution
and again at exit, before the original object/allocation sequence. The own
RuntimeBinding is an explicit frozen slotted class whose full methods have true
source origins; no generated class callbacks or original callbacks are aliased
or replaced. Binding accepts the independently constructed seal and never
rebases it after source or policy reads. Full fresh source/environment guards
continue in addition to live graph checks.

This does not establish all original/dependency callbacks, native custody,
private runtime assembly or real margin qualification. Original function code
checks and T07 installed-byte guards remain; full current source/profile/runtime
eligibility and independent capture/review are still required. Pure fixture
faults manipulate only newly loaded candidate helper objects, never original
Source/Service/Session/reader or library callbacks.

MA03 requires a nonnull closed current application journal scope before either
original assessment reader is called under the assessor Vault's exclusive lock.
It takes a non-aliased snapshot, holds no-follow ancestor/root and lock file
identities, requires owned700 roots and owned600 regular singly linked lock
files, and refuses the same physical root or lock inode. It verifies the exact
original independently selected workspace hash/ref/principal/scope correspondence
before delegation. The original reader, preflight, permissions and guards remain
unchanged. This prevents known own-lock recursion; the original reader's mutable
pathname/body custody and native qualification are separate obligations, not
replaced by this observer. It acquires no additional lock itself and creates no
private root, key, body or lease.

Full-tail reserves remain conservative under the strictest current call/operator
bound: they can refuse a tail that might use a fresh later operator. No current
period or deadline is extended. Failed episode81567 supplies no apply/assess,
full-tail, load/uncertainty or gate-overhead empirical calibration for this new
code. The new seal/capture costs must themselves be observed in an eligible
real diagnostic and included in an independently accepted empirical policy.

Independent review, complete new source/profile/family/assembly selection,
actual positive and separate negative episodes, exact retry/recovery/native

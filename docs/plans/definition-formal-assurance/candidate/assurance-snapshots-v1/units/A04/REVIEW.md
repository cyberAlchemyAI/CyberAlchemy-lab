## Definition forms and types

An admitted artifact's machine classification `semantic_kind: definition` does not classify its logical statements. A definition may declare a primitive, abbreviate existing vocabulary, specify genus and differentia, enumerate a finite set, characterize an implicit object, construct an object, define a recursion, or give operational meaning. Multiple forms can coexist; unresolved facets remain visible.

Types provide signatures: sorts, constants, predicates, relations, functions, records, states, transitions and traces. A nominal sort separates names in syntax. It does not show that two concepts have different extensions or that either extension contains an instance. Shared-carrier comparisons require an explicit alignment. The enriched interpretation contract reuses the fixed A01 declaration and formula vocabulary, while retaining the separate obligation to implement logical typechecking in C01.

The actual Hypothesis packet declares only a candidate record carrier. It has no encoded definition formulas and no adopted assumptions. This is sufficient for source review and insufficient for logical assurance. No programming type, ontology label or JSON schema substitutes for a domain definition.

## Roles, assumptions and proof targets

Roles explain what each selected statement does: definition, selected axiom, selected premise, constraint, hypothesis, proof obligation, derived claim, observation, explanation, or unresolved statement. A definition *of* Hypothesis or Axiom does not adopt the propositions of arbitrary hypothesis or axiom records.

A04 requires an exact assumption link for an externally assumed clause or selected premise/axiom. The statement, role and scope must agree; the assumption must be explicitly selected and have a resolved commitment. A substituted statement, unselected premise, omitted link or encoded premise with the wrong disposition is rejected. Hypotheses, explanations and proof targets cannot silently enter through this assumption route.

These controls do not detect every logically equivalent way to smuggle a target into its own premises. Stronger assumption assembly, entailment and noncircularity checks remain later work. All conclusions remain conditional on the actual selected assumptions.

## Logic and denotation

The foundation selects classical many-sorted first-order logic for the supported static fragment. Explicit formulas distinguish syntax from meaning. A structure interprets sorts, symbols and formulas; satisfaction is defined independently from a checker returning `true`.

The earlier finite prototype checks selected models and bounded searches. A satisfying model is a witness, not a proof that all models satisfy a target. Exhaustive absence in a declared finite search is bounded absence, not unrestricted inconsistency. A cancelled, exhausted or unsupported execution cannot count as an absence result.

Inductive leastness, temporal behavior, deontic meaning and empirical uncertainty require separate selected semantics and provider contracts. A recursive equivalence does not by itself select a least fixed point. A static invariant does not establish preservation through transitions. The new source/correspondence work makes none of those extensions silently available.

## Exact source identity and selection

A02 resolves each current lookup to one exact admitted ID/version entry. It verifies the source digest and checks the document's ID, version and term. A missing source, stale digest, duplicate version, incomplete lookup, selection of another identity, selected historical-only entry, or nonadmitted input fails explicitly.

All 189 admitted versions are captured, not only the 183 current ones. Historical rows preserve exact bytes and retain their historical effective state. They do not replace current selections. The snapshot also preserves the exact registry and selected admission-record bytes, for 201 files in total.

This is source integrity and selection evidence. It does not prove that the prose is consistent, that its author had real-world rights, or that an interpretation preserves its meaning.

## Provenance and admission references

Old admission records can contain postimages for older registry epochs. Capturing those records does not reapply their effects or mistake their old postimages for the current registry. Presence of a recorded admission or principal does not authenticate real-world authority. Semantic source acceptance, source fidelity and proof remain different predicates.

## Currentness, path confinement and publication

Reads use POSIX directory descriptors and reject symlink components and nonregular files. Source and registry bytes are rechecked after capture; the admission catalog is rechecked for newly introduced ambiguity. Publication checks current bindings again.

Publication uses an fsynced temporary file and an atomic create-only hard link in the destination directory. An existing output is preserved. Failed freshness checks do not publish a replacement or leave temporary output. Currentness is an observation at these boundaries; it is not a guarantee that the filesystem can never change afterward.

An offline snapshot can remain internally valid after live sources drift. A separate currentness check then reports the drift. Later consumers must repeat exact binding checks before making current claims.

## Source inventory and clause correspondence

A04 inventories every nonempty string leaf in the source's voices, boundaries, scope and claim ceiling. Each unit has an exact selector, character length, digest and source facet. The caller cannot shrink that denominator.

Each formal clause maps to an exact source span. Its selector, start, end, excerpt and digest must agree with the captured source. Duplicate mappings, unsourced formal clauses, forged excerpts and overlapping spans are rejected. A gap or missing entire clause leaves character accounting incomplete. Empty explanatory metadata outside the declared source inventory is not silently treated as logical content.

**Character accounting is textual accounting.** One field or paragraph can contain several natural-language claims. Covering its characters does not establish that every assertion was semantically decomposed, translated faithfully or assigned the correct role. The packet therefore leaves these conditions pending and never emits semantic readiness.

Encoded and externally assumed clauses require a formula. Explanatory, deferred and unresolved clauses cannot hide formulas. An explanatory disposition requires an explanation role. The default review packet retains every source text unit as unresolved, so inherited scaffold paragraphs do not become axioms.

## Explicit dependencies and source precedence

Semantic dependency links must name exact current source references and actual local clauses. Every declared semantic dependency needs a use site; a use site cannot substitute a different digest. A separately supplied required dependency denominator is compared explicitly. Imported traceability remains a separate lead and does not become a semantic edge automatically.

Completeness of the required dependency set is still a separate review obligation. The correspondence checker reports when that independent denominator has not been supplied. Transitive closure and strongly connected component analysis remain future graph work; textual matching is not a substitute.

Source precedence is explicit. Conflicts carry exact source selectors and an owner route. Required findings cannot be omitted. Attributable review references are evidence links, not self-issued owner acceptance or theorem results.

## Evidence strength and coverage

A total source inventory, structural schema result, source-bound candidate, checked model witness, finite exhaustive result, replay, unrestricted theorem and source-owner fidelity review establish different things. One global confidence rank cannot safely replace those distinctions.

The inspection includes the existing Craft formalization surface, its imported/generated Lean modules, Craft CLI Lean modules, and exact local pilot/foundation evidence.

Candidate layering, 2026-10-07. Authority effect: none. JSON decisions and exact task membership are in [dag.json](dag.json). The unit design and algorithms are in [IMPLEMENTATION-DETAILS.md](IMPLEMENTATION-DETAILS.md).

## Context and boundary method

The project is partially implemented: a finite pilot exists, complete source intake is verified, but no full translation has owner fidelity review. The primary user is the definition owner reviewing whether exact meanings remain distinct and jointly consistent. The main constraint is faithful semantic translation with honest evidence ceilings.

Layer value is the decision unlocked, visible outcome and risk reduced. Layer cost is implementation, verification and coordination work. Each layer stops at the smallest evidence-backed decision boundary rather than accumulating all providers, all definitions or live integration prematurely. Later layers preserve source binding, non-vacuity, exact-cause controls and review distinctions.

Drafting L2 interpretations can proceed once their declared input prerequisites exist; this does not promote L2 evidence before G01. Conditional stronger providers can be developed once profile requirements are sealed. Technical layer completion and owner semantic admission remain separate states.

## Per-layer planning slices

### L0 preservation slice

Keep the prior pilot directory immutable. Read the exact current interpretation and evidence; retain its finite-domain ceiling. DF01–DF06 in the analysis become successor requirements rather than retroactive edits. Cost is limited source inspection and evidence replay. Exit does not claim full Definition semantics.

### L1 implementation slice

First unit: A01.1, closed input envelope/decoder behavior with exact malformed controls. Then exact source capture, interpretation/relations policy, typed semantics and corrected pilot proceed along the DAG. Independent component work branches at A05/C03 and later IR/provider/evidence contracts. Owner fidelity review is an explicit gate with concrete examples ready beforehand.

Risk reduced: unchecked data or disconnected pilot assumptions being promoted into semantic assurance. Main costs: clause agreement, independent denotation, strict evidence verification and full selected-snapshot regression. The layer ends when those form one repeatable workflow; adding 183 interpretations or multiple providers at this point would not improve the selected-scope decision enough to justify their cost.

### L2 full-coverage slice

Use the editorial 14-family partition only to organize authorship and review. Every source has one T/O/E/R unit and a family closure join. S01 declares the actual dependency graph; S02 classifies pair relevance and carrier alignment; semantic cycles are joint units. Stronger/temporal provider routes are activated only by actual clauses and strengths.

Risk reduced: hidden source clauses, fake alias differences, silently unformalized dependencies and false proof coverage. Main costs: 183 interpretations, neighbour analysis, reviewer bandwidth and unsupported-fragment remediation. The layer ends at transparent complete accounting, not an unsupported claim that every meaning has a proof.

### L3 combined-theory slice

Compile one complete included theory and all required populations, then run joint satisfiability, inhabitation, distinctions and separately demanded universal properties. Diagnose conflicts with source-linked proposals and independently replay all evidence. Prepare exact owner review artifacts and staged proposed effects before any owner admission selection.

Risk reduced: pairwise success masking global contradiction, vacuity, stale proof reuse and evidence becoming authority. Main costs: cross-family composition, logical support, model verification, proof dependencies and actual human decisions. The exit report keeps unsupported clauses explicit; a no-admission branch is valid.

## Non-regression guarantees

- Exact source identity/version/digest and selected currentness remain mandatory.
- Distinction queries never become assumptions used to manufacture the distinction.
- Required inhabitants are checked jointly before semantic readiness.
- Aliases, subtypes, overlap and declared couplings retain their intended semantics.
- Malformed, missing, unsupported, timeout and stale outcomes remain non-pass.
- Scope/owner strings and grant templates do not authenticate real-world rights.
- A theorem is relative to its audited assumptions; full consistency needs a model.
- No candidate evidence or layer promotion grants admission authority.

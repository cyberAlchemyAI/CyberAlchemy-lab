## Work items

### G04.01 — Define the closed pack wire contract

Dependencies: G01.02, G01.03. Planned, not executed.

- Bind identity/revision, goal/intent, context, named consumer/use, concepts, dispositions/payloads, sources/evidence standing, owners, relationships, gaps, validation and ceilings.
- Reject unknown or contradictory fields and enforce conditional payload requirements.
- Version breaking additions explicitly; preserve imported source schemas and document legacy compatibility.

**Planned output names:** `contracts/definition-pack.schema.json`, `contracts/compatibility-amendment.json`. These are proposed paths within a future delivery package, not files created by this map.

**Complete when:** A new contract cannot silently change the old v1 protocol or claim admission from schema validity.

### G04.02 — Define reference resolution and posture records

Dependencies: G04.01. Planned, not executed.

- Record exact identity/version/digest/selector where available and admitted/current/historical/candidate/unresolved standing.
- Bind source resolution through actual Lab interfaces and exposed source-admission evidence.
- Separate provenance from authorization and resolve owner routes versus assignments distinctly.

**Planned output names:** `contracts/reference-standing.schema.json`. These are proposed paths within a future delivery package, not files created by this map.

**Complete when:** Missing or stale references are visible scoped obligations, not opaque nonempty strings treated as authority.

### G04.03 — Define use-specific readiness

Dependencies: G04.01, G04.02, G02.04. Planned, not executed.

- Separate pack well-formedness, review readiness, preparation completeness, promotion eligibility and named-consumer readiness.
- Map each open issue to the use it blocks; allow review of unresolved meaning.
- Name the responsible owner and refresh/invalidation rule for each gate.

**Planned output names:** `contracts/readiness-profile.json`. These are proposed paths within a future delivery package, not files created by this map.

**Complete when:** An open question can be reviewed without automatically authorizing or blocking every unrelated use.

### G04.04 — Define supplemental preparation input

Dependencies: G04.01, G03.02. Planned, not executed.

- Require explicit stable Definition identity/version, authority scope, semantic owner, domain voice, formalization/notation, boundaries, exact sources, consumers and index/drift routes.
- Bind each supplemental record to an exact pack/concept/revision and selected contract.
- Reject omitted mandatory values and untraceable semantic changes; never infer a Definition owner from owner_route.

**Planned output names:** `contracts/preparation-input.schema.json`. These are proposed paths within a future delivery package, not files created by this map.

**Complete when:** Every value absent from the pack is supplied explicitly or reported as a blocking obligation.

### G04.05 — Define revisioned session and handling state

Dependencies: G04.01, G04.02. Planned, not executed.

**Planned output names:** `contracts/session-state.schema.json`, `contracts/handled-record.schema.json`. These are proposed paths within a future delivery package, not files created by this map.

**Complete when:** Resume preserves actual user answers and gaps without creating a second canonical Definition registry.

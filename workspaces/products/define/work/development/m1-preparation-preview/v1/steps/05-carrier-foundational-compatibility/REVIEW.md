### Definition Evaluation Profile

A Definition Evaluation Profile is a reusable, owner-qualified, version-exact contract for evaluating a declared Definition representation and its review package. It specifies the subject kind, exact input and governing-contract selection, required checks, evidence requirements, outcomes, causal blockers, phase-specific aggregation, pre-decision eligibility and claim limits. It prescribes how an Evaluation is assessed; it is not an Evaluation execution or result. It does not select owner admission, apply an effect or change a Definition lifecycle state.

Example: The v2 candidate lists 14 checks and excludes admission selection/application from pre-decision validation.

[Complete three-voice candidate](definitions/definition-evaluation-profile/DEFINITION.md).

### Definition Lifecycle Profile

A Definition Lifecycle Profile is a reusable, owner-qualified, version-exact contract declaring the lifecycle states, initial posture, permitted ordered transitions, required evidence and owner authority, transition effects, invalidation and history-preservation rules for a declared Definition representation. It separates validation, review, admission selection and confirmed application. It specifies conditions for a transition; it is not the current state of a Definition, a transition event, an owner Decision or proof that an effect occurred.

Example: The v2 candidate preserves authored, validated, reviewed, admitted, superseded and withdrawn states.

[Complete three-voice candidate](definitions/definition-lifecycle-profile/DEFINITION.md).

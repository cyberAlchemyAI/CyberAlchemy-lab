# Define validation corrections

Chain: exact existing Definition selection -> private artifact contracts -> business ontology projection -> business/system bridge -> system ontology projection -> authored AlchLang -> actual generation and regression evidence.

Readiness uses the verified package's actual requested-use result. Definition materialization is proof only of the selected Definition derivation, not parameter completeness. Absence of a matching package observation cannot establish parameter readiness.

Handoff reports carry a ReportSubject (session identity, revision, source epoch, exact state snapshot and intended use). Inventory and canonical evidence manifests must equal actual current observations. Assessment and obligation results must agree with native recomputation. A read-only report factory/preview prepares fresh current reports without appending a note; ordinary recording still advances the journal. Appending handoff does not relabel the observed cut.

A reported handoff response binds the exact handoff id/digest/session/revision/source/use plus a bound original message and declared responder. Define checks type and correlation against the actual producer handoff in prior verified canonical history. A generic BindEvidence record is not a producer event. Referenced producer bytes are resolved from that verified event and retained with acknowledgement evidence. Actual responder authentication, owner acceptance and effect authority remain external.

Field contributions are checked against strict JSON Pointer observations over original source and bound draft bytes. Selected targets must resolve (explicit null placeholders are allowed); source selection must resolve. Distinct observed JSON values determine conflict counts. No normative field value is invented. Final full Definition/v2 materialization checks remain in force.

All new structured reports are Define-private bounded wire contracts with explicit schema versions, not newly registered generic business-record types. Existing definition standing is preserved. There are no shared Lab implementation or authority changes.

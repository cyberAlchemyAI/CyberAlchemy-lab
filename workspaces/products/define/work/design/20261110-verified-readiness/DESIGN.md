# Independently verified Define readiness

Chain: exact existing Definitions -> private artifact contracts -> business ontology projection -> business/system bridge -> system ontology projection -> authored AlchLang -> actual generation and regression evidence.

Keep declared and derived readiness separate. Frozen integrity authenticates selected bytes against their supplied hashes, not the calculation in those bytes. The existing Define package preparation protocol already validates actual required parameters, schema, scope, provenance and source values. Reuse it over the verified retained request/capture/member refs, with no file publication or live recapture. Its derived report supplies readiness.

A native Rule/Operation compares every top-level original/derived body field except the readiness declaration. This rejects application/contract/gap alterations against the bound request. Actual field observations are generic digests; only AlchLang decides which field may differ. The semantic assessment and handoff contracts retain a typed UseReadinessDerivation binding original request, original capture, native application report, field observations, declared result and independently derived result. ScopedAssessmentReport uses explicit schema v2. Current source epochs remain strict.

Only a derived Ready result can establish parameter completeness. A forged ready declaration on an incomplete package returns NeedsInput and retains both values. Complete packages remain Reviewable; missing observation remains noncomplete. Handoff and independent-process replay rederive identical evidence after original package/source removal. Derived reports and body projections are disposable observations, never a second package or source of truth. Memoization may reuse only identical current-source and already-byte-verified snapshots, never caller flags or unverified filesystem paths.

Keep shared Lab custody, permission, semantic admission, publication, construction enforcement and consumer acceptance outside Define. No new generic Artifact Type or canonical Definition admission is implied.

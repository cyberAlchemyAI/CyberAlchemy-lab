# Define

Define is maintained once, in `implementation/cli/alchlang`. The default `./define` and explicit `./define-alch` execute the same current AlchLang implementation. Package preparation, inspection, observed confirmation, materialization, reconstruction and replay use generated native policies and projections. There is no Python Define engine or predecessor CLI fallback.

Shared operations remain in the Lab: `implementation/artifact-runtime` supplies generic bounded JSON/schema, original-byte, hashing, publication and generation mechanics; `authority/artifact-types/definition/v2` owns the one Definition renderer; the existing shared Lab workspace runtime owns actual review, authorization and apply. The imported Craft 1.3.0 / AlchLang 0.7.0-candidate.0 compiler is unchanged.

Run `./define --help`, `./define doctor`, or `./define lab workspace resolve product/define`. `./define lab workspace verify` checks actual profile bindings and runtime placement. The Lab bridge forwards explicit arguments, creates no Project or Goal, installs no runtime, grants no permission, and provisions no store.

`./define example --output NEW_DIRECTORY` creates a request and source evidence for the actual User Journey Definition. Select real Project/Work context explicitly before `import-request`; the example supplies no migration Project or invented context. Then use `request`, `prepare`, `inspect`, `confirm`, `materialize`, `reconstruct`, and `show`. Outputs are candidates with no owner admission. Confirmation records the inspected package/request bindings and complete observation for durable replay.

Current journals use `cal.define.alch-session-event/v2` for ordinary commands and `cal.define.alch-session-event/v3` for source-bound semantic-preparation notes and the exact current source epoch. Older epochs are explicitly refused, not silently migrated. Retirement found no noncache Define journals. Portable v3 packages remain data and can be inspected/reconstructed; obsolete Pack v2 and the old standalone API/implicit Lab commands are retired.

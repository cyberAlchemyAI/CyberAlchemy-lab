# Alch Product Ontology authoring adapter

This L2 candidate binds Product Ontology authoring to the existing
`alch-product-business-ontology-v1` Definition Pack and Product Ontology source.
It asks only for capability, primary user, user job, outcome, and constraint,
then preserves the selected source's explicit non-collapse rules.

The adapter requires an exact digest-bound Definition Pack handoff, independent
grounding/non-collapse/orthogonality evidence, adapter validation, and exact
candidate-byte confirmation. It grants no admission, adoption, or effect.

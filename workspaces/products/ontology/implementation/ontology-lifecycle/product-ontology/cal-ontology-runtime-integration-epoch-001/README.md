# Ontology Runtime Integration Product Ontology Candidate

Status: validated candidate awaiting `G-D65-PRODUCT` owner admission

## Product Capability

CyberAlchemy should let a governed Context consume a deterministic,
challengeable ontology projection calculated from canonical per-node and
per-relation events at one exact event cut. The Context frames and consumes the
view; it never becomes another ontology truth source.

The capability must preserve the Context, event cut, sources, owners, and
challenge routes. Missing, mixed, stale, or unverifiable cuts fail closed
instead of producing a complete-looking view.

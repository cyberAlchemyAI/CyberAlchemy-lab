## Scope

The automated run uses axe WCAG 2.0/2.1/2.2 A/AA tags and best-practice checks. It observes the rendered states chosen for this site. It does not cover every combination of open disclosures, selected records, device settings or assistive technologies. Playwright WebKit is not actual Safari.

The collectors are site-specific observations and assertions. They are not a calibrated reusable UX validator and do not produce a universal usability score.

Use the original review's [WCAG 2.2 source card](../2026-10-12-site-review/source-cards.json) when interpreting targets. Keep contrast, keyboard behavior and semantic structure separate from newcomer comprehension. Reader responses and actual screen-reader/device sessions remain follow-ups.

CyberAlchemy Lab / Practical guides

Resume agent work

Rebuild a usable task context and check current permission before continuing.

Result and prerequisites

Prepare a usable continuation for an interrupted investigation. You need the saved Project State, exact assignment, current authority evidence, applicable policies, view request and selected freshness/expiry rules. Recovery of project knowledge and permission to act must both be checked.

At 10:10 UTC, Northstar task view 3 expires. The 09:45–10:15 delegation may still be current, but the expired view prevents continued reliance on that task context.

1. Pause and preserve permitted outputs

Record why the view is unusable and where the agent stopped. Persist only outputs permitted by the recording route, preserving their candidate standing and source references. Do not use temporary session notes as an accepted project conclusion.

If the same session remains active, refreshing its views does not itself renew or expand authority. If the session terminates, its machine instance and short memory end with it.

2. Select durable project knowledge

For a later session, select saved Project State: Work, comparison receipt, observations, assessment material, decisions and unresolved questions. Generate or obtain newly checked Context and Ontology Views under their applicable request, selection and freshness contracts.

The Context View example identifies included material by selector and digest, records exclusions and sets expiry. A structurally valid JSON view can still be unusable because its source or time conditions changed.

3. Recheck the authority envelope

Read the exact current assignment and delegation separately. Check eligible agent, scope, action kinds, policies, approval gates, period, revocation and budgets. At or after 10:15 UTC the old delegation cannot support later actions. A new session may need a new or renewed grant; copying the old context does not transfer permission.

Assignment describes expected participation. Delegation supplies its scoped grant only when its governing evidence is established. Neither a view nor an agent’s recollection grants authority.

4. Bind the continuation and its stop conditions

Create the applicable session envelope for the selected concrete instance, assignment, exact views, policies, authority, inputs, budgets and cursor. For a new session, use a new ephemeral machine instance and session-owned working memory. The Agent Session specimen shows the required fields.

Stop again if permission is revoked or expires, a view becomes unusable, the budget is exhausted or an approval gate is reached. Preserve the previous session’s records as history; do not silently resume its temporary memory.

Expected output and next action

Durable basis
Exact saved evidence and candidate assessment, with cause, wider impact and recovery still unresolved.
Task knowledge
Newly checked views with sources, limits and usable freshness/expiry conditions.
Permission
Current scoped authority for the intended action; no inferred extension from the previous session.
Continuation
Applicable session envelope and stop conditions, with a new instance when starting a new session.

Common failures: resuming on the expired view; treating saved state as permission; giving a machine instance durable private memory; calling an assessment accepted because it survived a session.

CyberAlchemy Lab / Reference examples

Complete record examples

Inspect the required fields, then compare a record with one precise defect.

What these examples establish

These are complete documentation specimens against the selected record schemas. Their invented example: identities have no registry standing. Passing a schema checks representation; it does not accept a record, establish its claims or grant permission. The links open local JSON files.

The saved input S1, output E12 and comparison receipt reproduce the fixed Northstar example: 10,000 required identifiers, 9,800 exported and 200 confirmed missing.

Recognize a semantic boundary

Suppose every required identifier appears in the export, but several email addresses have incorrect values. The identifier-coverage definition is satisfied; it says nothing about value accuracy. This is a boundary of the claim, not a malformed record.

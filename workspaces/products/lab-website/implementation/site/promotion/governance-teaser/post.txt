If your AI governance stops at permissions and privacy compliance, who decides what your agents call “complete”?

Customer 1 wants a file of its active database entries. Both agents use the same saved database copy. The service owner sets the requirements and accepts this definition: every entry matching Customer 1 and Active status must have its ID in the file.

One AI agent writes and runs the code. Another checks each selected ID and finds 200 missing out of 10,000.

The accepted definition settles the review: the export is incomplete. That is authority over meaning. Neither agent has permission to rewrite the rule to make the file pass.

CyberAlchemy Lab keeps the definition, database copy, code and failed review for the next agent. Corrected code still needs owner acceptance and separate permission for release to customers.

# ARE runtime module configuration

`runtime-configuration.alch` is the canonical candidate declaration for the
first exact production-style Module Port configuration. It binds one reviewed
semantic adapter and exposes three explicit consumer entry points. Entry points
are consumer/capability bindings, not HTTP routes or new authority boundaries.

The compiler verifies the adopted Constitution decision, factory source bytes,
reconstructed module manifest digest, unique module identities, distinct entry
semantics, and the no-effect ceiling before emitting ontology, runtime, and
evidence projections.

The generated configuration and current local conformance evidence satisfied
the technical prerequisites for the separately recorded runtime-admission
decision. The exact configuration is admitted, but it is not activated or made
the running default. The generated bytes retain their pre-admission projection;
the external decision record carries the admission state.

```sh
node ../../implementation/dist/cli.js check runtime-configuration.alch
node ../../implementation/dist/cli.js ontology runtime-configuration.alch
node ../../implementation/dist/cli.js build runtime-configuration.alch --out generated
node --test validate.test.mjs
```

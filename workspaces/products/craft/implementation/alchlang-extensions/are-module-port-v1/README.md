# ARE Module Port semantic contract

`module-port.alch` is the canonical candidate language declaration for the L3
static multi-module composition layer. It declares exact reviewed bindings, a
closed acyclic dependency graph, immutable module epochs, and zero authority
effect. Its finite fixtures exercise identity non-collapse and ordered/distinct
public diagnostics.

The compiled `generated/` directory contains the derived ontology, DomainSpec
projection, runtime projection, source provenance, and finite validation
report. These generated artifacts and passing tests are construction evidence;
they do not adopt the candidate Constitution, admit a module, activate runtime
enforcement, or authorize effects.

The `governance-candidate/` directory binds the exact L3 source, compiled
manifest, implementation, tests, compatibility/retirement policy, degraded
behavior, and owner boundaries. Its validator keeps product approval,
Constitution adoption, runtime admission, and activation as separate ordered
decisions. Product approval is selected for the exact tested L3 candidate, and
the exact digest-bound capability-local Constitution is adopted for its stated
selector. The first exact production-style static configuration and current
evidence for its bound adapter are selected, and that exact configuration is
now admitted. The exact Rust binding is admitted, operational authorization and
activation are selected, and the separately evidenced local executable cutover
is now realized. The decision CLI, app server, and gateway start only after the
exact packaged Linux x64 Rust release artifact verifies the subject. Startup
does not invoke Cargo, a compiler, or a package manager. This enforcement
grants no effect authority and does not install external hooks, publish,
release, or deploy anything.

Validate it from this extension with:

```sh
node --test governance-candidate/validate.test.mjs
```

Build from the repository root:

```sh
node language/capabilities/alchlang/plans/general-compiler-v1/implementation/dist/cli.js check language/capabilities/alchlang/plans/general-compiler-v1/extensions/are-module-port-v1/module-port.alch
node language/capabilities/alchlang/plans/general-compiler-v1/implementation/dist/cli.js ontology language/capabilities/alchlang/plans/general-compiler-v1/extensions/are-module-port-v1/module-port.alch
node language/capabilities/alchlang/plans/general-compiler-v1/implementation/dist/cli.js build language/capabilities/alchlang/plans/general-compiler-v1/extensions/are-module-port-v1/module-port.alch --out language/capabilities/alchlang/plans/general-compiler-v1/extensions/are-module-port-v1/generated
```

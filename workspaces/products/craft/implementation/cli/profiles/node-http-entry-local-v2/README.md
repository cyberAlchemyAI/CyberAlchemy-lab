# node-http-entry-local-v2

Version1.0.0, candidate locked architecture package for craft.profile-project/v2-candidate. It supplies audited formal-language and identity data, empty-effects settlement and typed request transport. The business author supplies accepted meaning/definitions/owner decisions and exact Rule/Mapping/Operation correspondence; package metadata never creates acceptance, permissions or formal proof.

Each application entry owns its transport module. Generated public Request handlers need no caller-native store implementation for zero effects. No persistence, event publication or durability is implied.

## Open Questions

Additional providers, protected access, arbitrary business expressions, cross-source linking and new mechanism families require separate qualified support. Local hosting, TDE, EVF and publication remain deferred.

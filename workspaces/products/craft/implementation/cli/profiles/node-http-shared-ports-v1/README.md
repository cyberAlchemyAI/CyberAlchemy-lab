# Shared-port Node HTTP profile

One module owns the typed HTTP transport port used by both business entries. It selects injected transport when supplied and otherwise calls fetch only at invocation. Source behavior stays in checked business callables. This is a structural profile variant with an additional owned component and actual dependency imports.

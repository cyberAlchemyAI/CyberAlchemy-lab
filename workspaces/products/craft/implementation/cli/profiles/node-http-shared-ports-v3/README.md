# node-http-shared-ports-v3 1.0.0

Business-authoring successor selecting the finite ground Entity Boolean Operation recipe. Formal, identity, empty-settlement and HTTP transport assets are copied byte-for-byte from `../node-http-shared-ports-v2/`; their manifest hashes retain that provenance. This new manifest captures v3 authoring and wire conventions; the v2 package remains unchanged.

Transport ownership: `shared`. Route prefix: `/`; request bytes: 16384; timeout milliseconds: 2000. Shared transport is explicitly emitted once and consumed by each generated Operation entry through the existing profile renderer. Local transport is owned by each entry. Business predicates, access and effects remain source-owned.

# business-acknowledgement

Synthetic accepted meaning/definition/owner-decision records demonstrate the business-only input contract. They confer no formal proof or real owner authority. Copy domain.alch, business-semantics.json and project.json into the consumer root, then follow [the guide](../../../docs/BUSINESS-APPLICATIONS.md). oracle.json contains independent expected values and negative cases.

## Open Questions

This example uses empty-effects settlement. Persistence, external API calls in this application slice, protected access and arbitrary expressions require separately supported mechanisms. Local hosting, TDE, EVF and publication remain deferred.

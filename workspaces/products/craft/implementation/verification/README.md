# Broader local verification

Run `node craft/implementation/run.mjs verify` from the Lab root after the local build. It creates unpublished archives and an isolated unpacked consumer in a fresh temporary directory, exercises the existing installed application tests serially, then runs TDE, EVF and pure Body War reference checks. Failed suites remain failures; the command writes the current result and exits unsuccessfully when gaps remain.

The inherited application deadlines allow multi-hour runs. Current phase logs are written under `craft/implementation/.local/broader-applications-*.log`; the application checks finish before component compilation/tests begin. Use the existing `check` command for the shorter relocation/ontology iteration.

The application matrix uses the existing owners: eight binding tests, nine connected tests covering six applications, and six portfolio tests covering customer success, contract workbench and cited RAG integration. Recorded model/provider/reviewer fixtures exercise source selection, generation, approvals, persistence, reconnection, unknown original intent and protected APIs. Optional ARE agent integration, live providers, measured model quality and process-crash certification are separate.

The offline installation repackages the exact already-installed TypeScript, OpenAI and PDF.js dependencies because this host lacks their original registry tarballs. These temporary archives are test inputs. This is an actual unpacked local installation; it does not certify installing from a package registry. Node, Cargo and shared editable runtimes are referenced in place. No install script, listener, Docker project, publication or global runtime switch is run.

Current results replace [the broader report](../../work/outcomes/current-verification/broader-qualification.json). Diagnostic logs, raw runner results and temporary-location metadata live under ignored `implementation/.local`. Test sources and fixtures are functional inputs; [input origins](input-origins.json) record the selected upstream owners without importing their old reports. Fixture files remain through the original owners' disposal hooks. The owned temporary workspace is removed after report collection; `qualify.mjs --cleanup` performs the same guarded cleanup for a staged run. Current evidence does not require temporary archives or run trees to remain.

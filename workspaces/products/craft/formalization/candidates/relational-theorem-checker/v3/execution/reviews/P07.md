# P07 review: runs preserve evidence and cache expectations have an independent origin

P07 passes its three acceptance criteria and 42 controls. Three actual fresh rich qualifications include two distinct requests sharing the same cache and a fresh resume of an interrupted request. Their supervised times were approximately 119, 113 and 103 seconds. All 20 obligations were checked in each run. These measurements are observations, not selected defaults.

Each run gets a new owned directory. Exclusive phase records bind its original raw request, policy, source fingerprints, prior phases and available outputs. The final worker and supervisor records are joined only after complete supervision. Finalized files use mode 0400 and directories use mode 0500. The second run preserved every first-run byte, and the original accepted cold witness/dependency files remain current after the new warm runs.

Cache expectations come from accepted evidence rather than the cache's own metadata. P02 independently pins the 35-module manifest; P05 independently pins 2,040 imported Lean/Std artifact bindings. The key also includes compiler/kernel, catalog, generator and layout policy. The review added imported closure checks to the final inspector and gave the owned response a distinct closed schema identifier, avoiding ambiguity with the original supervisor response.

Resume preserves the interrupted evidence and validates its exact source, raw-request, policy, ownership and phase chronology inside the new supervised worker. It starts a different run and repeats fresh qualification. A changed raw request, changed policy, transplanted output, saved completion flag or oversized resume selector does not authorize a resumed qualification or application.

Execution synchronization now separates remaining required work, selected optional work and resolved optional work. All seven selected extensions stay outstanding until accepted. Only an actually unselected extension may be resolved as not-needed. Required work cannot be excluded by that label.

This proves operational repeatability under the mediated trusted-host boundary, not filesystem durability or exclusion of an equivalent-privilege external writer. Saved inspection is currentness only; every result still has application_authorized false. Cleanup returns proposals and deletes nothing.

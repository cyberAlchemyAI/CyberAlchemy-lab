# L2 interface boundary

## Definitions

- [change-proposal](../schemas/change-proposal.schema.json) — Exact baseline and proposed graph/registry/rules identities; author labels are checked against an independent diff.
- [semantic-diff](../schemas/semantic-diff.schema.json) — Normalized exact changes computed by the consumer, not accepted from author labels.
- [obligation](../schemas/obligation.schema.json) — An independently required statement with exact premises, scope and permitted evidence methods.
- [obligation-set](../schemas/obligation-set.schema.json) — Complete required set generated from actual diff and selected policy; client-submitted subsets are not authoritative.
- [model-witness](../schemas/model-witness.schema.json) — Finite inhabited interpretation or countermodel, checked against every theory axiom and the claimed target.
- [compatibility-report](../schemas/compatibility-report.schema.json) — Selected-data compatibility, invariant preservation and model conservativity are independent claims.
- [obligation-request](../schemas/obligation-request.schema.json) — Request contract for deriveObligations; exact references must resolve through the local artifact store.
- [model-request](../schemas/model-request.schema.json) — Request contract for checkModel; exact references must resolve through the local artifact store.

## Behaviors

- **C-deriveObligations**: Compute the exact semantic diff and derive every required hard obligation using server-selected policy. Complete obligation set with coverage statement, including L3 obligations for rule changes.
- **C-checkModel**: Verify a nonempty interpretation against every bound axiom; countermodel also negates the target statement. Checked witness with exact finite scope; a fully checked countermodel may refute a universal implication.
- **C-artifactTransport**: For named JSON envelopes reject invalid UTF-8, duplicate keys, schema mismatch and unsupported documents. Store raw proof, statement, provider and dependency bytes as untrusted artifacts. Resolve each operation's expected role/schema independently of upload labels; hash original bytes without reserialization. Artifact identifiers never grant read permission; access remains principal-scoped.
- **C-jobLifecycle**: Queued -> running -> completed/timeout/unavailable/failed; queued/running may cancel. Terminal states are immutable. HTTP 202 and completed job state say execution happened, not that an obligation was satisfied.
- **C-layerEvidenceGates**: F0 starts with P01 relational semantics, P03 independent formal predicates, P04 Lean reference checker and P05 general soundness review. B00 baseline refresh and P02 schema/API/decoder alignment follow that accepted evidence. Every later task requires current predecessor evidence; G2 closes supported non-rule scope while I06 closes rule obligations. Contract authoring does not complete any implementation/proof gate in the DAG.
- **C-protectedLineage**: Match targetVersion, effect, scope and epoch against legitimate roots across all indirect rule paths. Conformance may coexist with independently justified admission; conformance cannot justify admission.
- **C-compatibilityClaims**: Check selected data, generic invariant preservation and model conservativity separately. A conservative-extension claim covers every base model via an expansion with unchanged old reduct.

## Acceptance boundary

These interface definitions are authored. Their executable semantic behavior and proof obligations remain the corresponding DAG tasks.

# Successor semantic contract

This is a finite, positive, candidate-only profile. Exact references carry id and revision. Contextual conformance observes only a member assertion of a graph satisfying the F0 invariant, with exact subject, target, scope and supplied accepted assessment. A valid unrecorded assertion is only a candidate.

ConformsTo is a sealed source observation with [reference, reference, scope] arguments. TargetKind is sealed with [reference, text] arguments. Kind text uses the independently declared kindName map. Both require checked projection support; no user seed or rule head may produce them. Unary Conforms is an existential compatibility observation computed from the projected initial inventory, not a new rule writing an old predicate.

Producer class is orthogonal to authority-root Role. Fresh ordinary signals may read observations. Checked roots still come from independently supplied exact reference/effect/scope/epoch evidence. No graph observation grants authority. Generic Horn models may contain additional ordinary truths; source-faithful profile models interpret sealed observations exactly as the captured inventory. Proof and API claims name their model class.

PotentialNorm means exact inherited Origin. ActiveNorm additionally needs an exact interpreted condition revision/context/key with a consistent supplied holds evaluation. Fulfillment is deferred. Require/forbid conflict is retained without explosion; permit grants no organizational authority. Different-key evaluations are different contexts. Contradictory selected statuses for one exact key invalidate activation. Missing status remains unknown. Unknown alongside a differing selected status is also inconsistent in this first profile; a different selection policy needs a new profile.

Condition/source mappings must bind profile, condition revision, subject, target, scope, exact context and temporal epoch when relevant. Runtime interpretation records bind condition revisions that the legacy stress label alone cannot identify. Timeless meanings use no invented epoch. Accepted assessment truth, external clocks and issuers remain explicit assumptions.

The supported rule-only extension keeps domain, roots, old predicates, rules and initial facts unchanged, appends fresh derived ordinary predicates and positive range-restricted function-free rules. Bodies may read old or fresh predicates; heads cannot write old, sealed or protected predicates. Every-old-model expansion and finite termination need universal statements, not fixture-only success. Graph/fact/domain/assessment migration is a distinct baseline transition.

Resource preflight occurs before grounding or conflict products. Exhaustion is unknown and prevents closure, absence and readiness claims. No source schema, issuer, new solver, general negation, chain delegation, override precedence or live application semantics is inferred from these choices.

The 41 source relation review remains the requirement inventory. These are explicit candidate defaults, not modifications to source authority definitions or claims of human approval.

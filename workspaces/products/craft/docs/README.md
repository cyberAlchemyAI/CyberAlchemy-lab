# Learn Craft

Start with the [step-by-step Craft guide](../COMPLETE-GUIDE.html) ([Markdown version](../COMPLETE-GUIDE.md)). It follows one Customer Success application from a renewal question to a checked, locally observed result. You can read it without knowing Craft or AlchLang first.

The guide takes this path:

1. The account and the result we want.
2. What Craft does with a business decision.
3. The meta types that give each part a job.
4. How those parts connect into one application.
5. How AlchLang declares the account, score, policy, read, and review.
6. What profiles and a host add around that source.
7. How to run the focused example and interpret its result.

After that application, use [AlchLang syntax](reference/alchlang-syntax.md) to look up a declaration, and [profiles and profile creation](guide/alchlang-profiles.md) when you want to change how a supported model is built. [Concepts in plain language](reference/concepts.md) is a short glossary.

# Profiles

**Author and select realization profiles**

Enable an owner or builder to express checked technical profile choices for supported architecture, target-language and runtime realizations while keeping business meaning separately owned.

**Compose compatible profiles and inspect constraints**

Enable a builder to combine supported source-selected profile packages and child consumers while inspecting compatibility, capability coverage and provenance before generation.

**Bind profiles to exact native and provider realizations**

Enable a builder to connect supported checked source/profile selections to exact existing business, native, provider-stage and runtime owners while preserving ABI, command identity and resource/permission boundaries.

Acceptance conditions and exclusions are part of the current capability definition. Candidate descriptions and imported definitions do not establish runtime qualification.

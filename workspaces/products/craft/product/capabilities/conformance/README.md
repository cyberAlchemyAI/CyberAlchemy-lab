# Conformance

**Observe target conformance and drift**

Enable a reviewer to compare exact generated or selected targets with declared source/profile/realization identities and report bounded drift.

**Verify supported static and native semantics**

Enable a reviewer to run selected static/native/semantic verification and negative controls for supported generated TypeScript, Python and Rust artifacts.

**Reproduce bounded conformance and assurance evidence**

Enable reviewers to reproduce selected conformance-factory graphs and inspect exact technical assurance certificates without inflating their claim.

Acceptance conditions and exclusions are part of the current capability definition. Candidate descriptions and imported definitions do not establish runtime qualification.

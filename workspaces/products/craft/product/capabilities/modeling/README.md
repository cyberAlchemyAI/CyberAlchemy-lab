# Modeling

**Author and check typed source models**

Enable a builder to author and validate supported typed source models with explicit concept, field, behavior and ownership declarations before selecting an implementation.

**Compose source modules and typed relationships**

Enable a builder to compose supported features/modules, Interfaces, Mappings and relationships while checking identities, endpoint rules and boundary constraints.

**Review meaning, source identity and coverage**

Enable an owner and builder to review supported business-source projections, preserve source/acceptance lineage and inspect omitted, rejected or unsupported declarations before construction.

Acceptance conditions and exclusions are part of the current capability definition. Candidate descriptions and imported definitions do not establish runtime qualification.

# Observability

**Inspect bounded runtime and effect observations**

Enable an operator/reviewer to inspect source- and runtime-identity-bound traces, transitions and effect observations without promoting fixtures or metadata into production truth.

**Qualify bounded behavior and application quality**

Enable reviewers to retain explicit denominators and reproducible selected checks for application behavior, recipe/runtime expectations and model-dependent quality.

Acceptance conditions and exclusions are part of the current capability definition. Candidate descriptions and imported definitions do not establish runtime qualification.

# Generation

**Generate supported business behavior**

Enable a system builder to generate supported typed business behavior from checked source models using explicitly selected realization profiles, while retaining source identity and unsupported residue.

**Generate selected applications and services**

Enable a system builder to generate supported application/service implementations and their assembly from checked business input and explicit technical profiles, preserving original runtime owners and required host resources.

**Generate contracts, SDKs and traceability views**

Enable builders and reviewers to obtain checked contract data, supported client/service interfaces and source-linked business/system views from the same selected application/model inputs.

**Export supported formal models**

Enable a reviewer to export supported bounded source models into established formal-language representations with explicit scope and provenance for separate analysis.

Acceptance conditions and exclusions are part of the current capability definition. Candidate descriptions and imported definitions do not establish runtime qualification.

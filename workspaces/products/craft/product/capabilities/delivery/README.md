# Delivery

**Prepare reproducible source and tool distributions**

Enable a builder to prepare and verify exact source/archive/native/toolchain closures and clean installed consumers for a selected supported distribution.

**Prepare and qualify inert deployment recipes**

Enable an operator to generate/inspect selected deployment and operational recipe artifacts and evaluate bounded recipe qualifications before any separately authorized external effect.

**Plan supported compatibility transitions**

Enable builders to prepare supported model/selection compatibility transitions and retain predecessor/successor identity and unresolved migration obligations.

Acceptance conditions and exclusions are part of the current capability definition. Candidate descriptions and imported definitions do not establish runtime qualification.

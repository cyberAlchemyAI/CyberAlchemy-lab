# Evf

**EVF — bounded validation and evidence verification**

Enable a Craft system owner and evidence reviewer to run selected tool-backed audits, independently verify source-bound results, and preserve supported, unsupported and unresolved evidence scopes without inflating the resulting claim.

Acceptance conditions and exclusions are part of the current capability definition. Candidate descriptions and imported definitions do not establish runtime qualification.

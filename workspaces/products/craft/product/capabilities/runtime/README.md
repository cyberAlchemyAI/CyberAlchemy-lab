# Runtime

**Execute supported stateful operations**

Enable supported generated operations to enforce declared decisions and update owned state through explicit transaction and authorization boundaries.

**Coordinate durable workflow and recovery**

Enable a system owner to coordinate supported workflows and plan/reconcile recovery from exact completed-step and unknown-outcome evidence.

**Deliver and reconcile events and external effects**

Enable a system owner to retain command/effect identity, commit/acknowledgement boundaries and inspectable recovery for supported event, outbox and external-effect paths.

Acceptance conditions and exclusions are part of the current capability definition. Candidate descriptions and imported definitions do not establish runtime qualification.

# Ai Data

**Use bounded inference and agent resources**

Enable an application owner to bind checked model observations and optional bounded agent proposal loops to original business decisions, access controls and exposure/effect accounting.

**Process, retrieve and release permissioned sources**

Enable an application owner to parse supported documents, retrieve source-bound results and release selected content with current recipient/access/provenance checks.

Acceptance conditions and exclusions are part of the current capability definition. Candidate descriptions and imported definitions do not establish runtime qualification.

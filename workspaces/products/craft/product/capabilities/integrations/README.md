# Integrations

**Check integration and lifecycle contracts**

Enable builders to declare/check responsibility-specific API, persistence, messaging and failure/migration contracts before selecting concrete provider resources.

**Use supported bound integration adapters**

Enable an application owner to use selected supported inbound/outbound and connector adapters with exact operation identity, completion and failure semantics.

**Enforce access, policy and credential lifecycle**

Enable an application owner to enforce selected Entry-local authorization and source-authored policies, and manage bounded credential/identity resources with explicit owner and recovery boundaries.

Acceptance conditions and exclusions are part of the current capability definition. Candidate descriptions and imported definitions do not establish runtime qualification.

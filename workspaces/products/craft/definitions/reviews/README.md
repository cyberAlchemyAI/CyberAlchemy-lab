# Definitions — reviews/ (pre-canonical staging)

Staging area for definition terms that are **not yet canonical**, per
[../DEFINITION-LOCALIZATION-ROUTE.md](../DEFINITION-LOCALIZATION-ROUTE.md).

- One file per term: `reviews/<term>.md`, holding a `represented` card while it is localized/reviewed.
- A term here is **not** domain authority until the owner canonicalizes it (moves it into
  [../DEFINITIONS.md](../DEFINITIONS.md) + a row in [../DEFINITIONS-INDEX.md](../DEFINITIONS-INDEX.md)).
- Using a `represented` term as authority before canonicalization is a drift defect that
  [../DEFINITION-DRIFT-AUDIT.md](../DEFINITION-DRIFT-AUDIT.md) flags.

Current review residues are historical or future-formalization inputs; none is active authority. Layering
governance and drift governance were promoted to `domainspec-v2-D16` and `domainspec-v2-D17` and are no longer
owed definition candidates.

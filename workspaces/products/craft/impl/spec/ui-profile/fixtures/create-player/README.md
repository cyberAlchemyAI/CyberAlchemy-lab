# Create Player Synthetic UI Calibration

This directory is a preregistered, synthetic-only mechanical calibration
corpus. It contains one machine specimen per required UI concept and six cases
per specimen:

- `positive` accepts;
- `nearest-neighbor`, `malformed`, `criterion-erased`, and
  `changed-consequence` reject;
- `label-erased` accepts to prove formation does not depend on the human label.

The manifest explicitly denies real-corpus and independent-replication claims.
Passing this corpus establishes validator mechanics only; it does not activate
DS-D1 kinds, change DS-D8, or prove empirical universality.

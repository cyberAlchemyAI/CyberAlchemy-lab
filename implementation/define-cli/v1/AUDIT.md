## Remaining model work

1. Define output retains its candidate pack schema. It is not automatically the Lab's three-voice Definition carrier. Canonicalization, owner selection and admission require the existing Definition preparation/review route.
2. The twenty upstream handled records and their older owner/source references have not been promoted or rebound as Lab registry records.
3. Source validators still report the documented historical drift and wider compilation gap. The working selected successor has an independent claim and evidence boundary.
4. The durable API consumes caller-supplied access context. It does not authenticate a human principal, establish tenant security or grant repository effects.
5. Finite non-collapse checks are useful rejection rules; they are not a proof over the complete admitted definition set.
6. Atomic build publication requires Linux `renameat2` support. No replacing-rename fallback is enabled.

These boundaries limit adoption and admission claims. They do not prevent the documented local candidate CLI workflow.

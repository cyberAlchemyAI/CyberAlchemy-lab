# Generic artifact runtime adapters

These adapters provide bounded strict JSON/byte handling, canonical-entry encoding, JSON pointers, exact hashes, anchored filesystem reads, atomic no-replace publication, and execution of verified generated pure AlchLang artifacts. They contain no Define readiness, Pack composition, semantic acceptance, owner selection, materialization or admission policies.

`exact_io.py` reuses the generic byte mechanics from the former standalone implementation. It is deliberately outside the Define Product and has no dependency on `define_core`. `pure-operation.mjs` loads exactly the generated bytes bound by the supplied manifest; the manifest is an integrity selection, not publisher authentication or an owner grant.

`json_construction.py` encodes explicit bounded JSON construction steps emitted by
a model. It accepts no executable expressions or domain defaults. The portable
checks in `verify_json_construction.py` cover binding mismatch, missing sources,
overwrite, sparse arrays and encoding bounds. Linux filesystem publication and
Define workflow integration remain unqualified for this new operation.

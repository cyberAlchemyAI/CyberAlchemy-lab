# Prototype definitions: Ontology Product event-runtime realization

Status: prototype definitions  
Authority effect: none

## Package-to-event realization

A deterministic translation from one exact admitted-root navigation projection
into canonical, per-subject node and relation event histories accepted by the
D65 Rust engine. Translation does not make the package or projection a replay
source; the emitted events become the runtime replay source.

## Integration epoch record

An immutable envelope binding one translation attempt to the exact navigation,
root-admission decision, Rust runtime, and compiled event-sourcing contract.
The record identifies the event set but does not calculate ontology state.

## Calculated subject snapshot

The latest complete resulting state for one node or relation at an exact global
semantic cursor. It is rebuildable cache evidence and never an authority source.

## Realization observation

A derived summary of the event cut, latest snapshots, Context projection, source
digests, and preserved authority limits. Equality across independent runs is
determinism evidence, not runtime adoption or Product approval.

## Realization relation

The bridge claim that the approved Ontology Product contract is implemented by
the D65 event runtime. It is eligible only when the frozen Product candidate and
its current Product tests cover exact source bindings, translation, replay,
latest-state calculation, governance joins, recovery, and hostile failures.

## Determinism and fail-closed behavior

The observation timestamp is recorded once after source currentness passes and
is an exact build input. Source identities include namespace, selected item and
root/file/digest/selector. Native event order, qualified local predicate and
endpoint identity remain deterministic. Original byte digests, row structure
digests, newly generated Source carrier digests and native event digests are
distinct bindings.

An independent manifest pin, exact file closure, actual current signed carrier
and Definition witnesses, disposition reconciliation, schema checks, source
observations and native replay are all required. Changing a digest envelope
does not establish domain conformance. Unexpected files, extra qualifiers,
changed source epochs, source/endpoint aliases, authority claims and overwritten
packages fail. The CLI writes only the selected empty candidate directory.

Declared source locators are checked as exact Markdown heading lines or literal
text occurrences. Unique, ambiguous, absent and blocked observations are retained
separately. A literal match is not semantic selector authority or transitive
dependency closure. Missing source revisions do not become satisfied merely
because this metadata package can be constructed.

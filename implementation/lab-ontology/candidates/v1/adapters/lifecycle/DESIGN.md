Status: candidate implementation. Original admitted Rust library and frozen Lab runtimes are unchanged. Actual source withdrawal and signed transaction mapping remain integration obligations.

## Exact source and type translation

The selected signed C12 source archive is independently replayed. Its exact Work transaction target selector, original transaction bytes, operator scope, immutable record digest and Project semantic/governance history tuples are resolved separately from the representation. Current carrier schemas and exact Definition revisions supply independent normative-selector digests.

Node/v2 is translated field by field: semantic components bind current carrier types and selected Definitions; use obligations and forbidden collapses have explicit profile declarations; source properties are closed and schema-bound. Missing or edited fields fail. Definition identity and exact selected revision remain distinct in the selector witness. Labels never determine identity.

The candidate Rust fork adds two closed property profiles and rich semantic checks to the inherited validator region. The rest of the inherited library, its 23 regression checks and their original fixture bytes are preserved. The old empty profile remains supported. Node properties carry exact carrier/subject/schema/mapping trace; relation properties carry exact source/target revisions and qualifier digest. Original qualifier values and source bytes remain in separately verified witnesses.

## Histories and governance

New events are canonical-format events in an owned disposable candidate ontology store. They are not admitted ontology events. The native reducer seals and verifies independent semantic/governance chains and joins governance through exact event ID, digest and cursor. The original Project histories retain their separate identities, cursors and digests.

The candidate confidence profile explicitly declares `not-assessed` as an unknown sentinel for both evidence support and owner reliance. It supplies neither positive evidence confidence nor commitment. Its exact vocabulary/profile is an additional S02/R08 review member. No existing legacy confidence scheme is repurposed.

Challenge mapping resolves original Event and Contract bytes, exact challenged subject revision, ground and modes. A resolved candidate contest requires its exact source Decision. The source gate reference uses a reversible witness to a native safe identifier. The actual-owner authority gap remains typed residue; candidate resolution is not canonical owner disposition. Challenge-only appends must preserve every semantic event byte.

## Independent lifecycle and recovery

Retirement is reversible; removal is terminal. Retiring/removing a relation before its node preserves the active endpoint invariant. These changes apply to representation lifecycle only and do not withdraw the source. Original source state, record bytes and signed archive remain unchanged. A genuine source-withdrawal mapping still requires separate signed effect and eligibility proof.

Every append and read checks the selected profile, original source/Definition witnesses, native executable pin and full native event file closure. Changed originals, closed/expired owned scope, wrong exact governance joins and relabeled Project events fail. Cold reconstruction reads original native bytes in a new process, independently replays the original Lab archive and reconstructs rich selector/type/connection/challenge witnesses. Checkpoints remain calculated views and must match full replay.

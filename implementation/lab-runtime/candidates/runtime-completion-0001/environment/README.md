# LC-U05-01 selected dependency and environment adapters

The public entry points are the reviewed `dependency_graph.reader.RoleReader`,
`dependency_graph.semantic.verify_graph`, and `environment.composite.verify_environment`.
They preserve selected source/profile/cut identity and original table order;
proof references never become semantic Artifact edges. The complete T08 reader
and semantic checkpoint was independently accepted before T09 consumption.

The environment adapter verifies the complete original descriptor, R02 mapping,
720 ordered execution requirements, eight module origins, selected installed
member bytes, wheel contents and 77 ELF metadata closures. The fixed original
execution-selection digest prevents coherent candidate omission or reordering.
The AC07 map identifies actual original producer/consumer functions and their
byte/rendering, root, preimage and source relationships without executing them.

These are inert adapters. Their success does not qualify real protected access,
current host custody, file modes, loader/CPU ABI behavior, original proof members,
installation, original task acceptance or effect authority. Those obligations
remain explicit in returned results and the individual contracts. Public errors
are bounded codes; protected values, locators, schema excerpts and exception
chains are not diagnostic output.

The final test driver selects a literal input manifest before executing a closed
test script, verifies all effective selected bytes before and after, and rejects
added source files or source aliases. Source loading uses the accepted regular
file cache prefix with `-B -S`; historical `-I` flags are preserved as data and
do not imply that an environment-variable cache policy works with isolation.
Later combined-unit source changes require a fresh independently selected source
closure; the frozen historical selection must not be silently widened.

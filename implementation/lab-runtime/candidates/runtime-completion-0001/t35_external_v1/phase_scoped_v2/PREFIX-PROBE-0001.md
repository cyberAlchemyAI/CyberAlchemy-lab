# Phase-scoped Source and Reader prefix fixture

`prefix_probe.py` is a disposable execution candidate for the reviewed
`phase-plan-0001.json`. It retains the prospective 27-role template map in
memory and O_EXCL-creates only 12 Source/Reader role leaves plus three controls.
Mapper and Context paths are absent before Source runs and remain absent after
Reader closes. The Source manifest selects the 15 materialized leaves and the
exact 1,703 sparse repository input bindings; it does not select the 15 future
role templates.

The first bubblewrap child executes the relocated, hardened historical Source
builder with a fixture-only signer and a writable `source/packages` mount. The
parent checks the exact package member names, manifest claims, preexisting
stage digest stability, and 53-leaf poststate. The second child receives the
same family read-only. Its Reader bridge is a separate pinned snapshot file
mounted over the bridge import path only in that second namespace. It exercises
`SelectedReader.guard`, `package`, and `open_signed`, validates the closed
report and three independent wrong-pin refusals, and requires an unchanged
54-leaf family tree. Both children have a sparse selected repository snapshot,
private `/tmp`, cleared environment, bounded output, and no protected host
roots mounted. The owned scratch root must be absent after the context exits.

This proves only a disposable Source→Reader prefix if the probe succeeds and
an independent review confirms its exact bytes and receipt. It does not sign
or materialize Mapper, Context, a production phase receipt, or an installed
T02 custody gate. The Source package uses a fresh ephemeral fixture signer;
system Python and shared libraries are mounted/version-checked rather than
SHA-closed. No actual protected family, issuer, service UID, or WSL host
qualification is selected here. The v1 all-30 Source/Reader evidence remains
immutable and describes a separate fixture.

Run pure guards with:

`python3 -m unittest discover -s implementation/lab-runtime/candidates/runtime-completion-0001/tests/LC-U02-05 -p 'test_phase_scoped_*v2.py' -v`

The Source→Reader probe must not be executed until an independent static review
of the exact source/test hashes signs off its bounded effect envelope.

# Disposable historical Reader probe

This is an inactive LC-U02-05 fixture route. It executes relocated and hardened
historical Source builder logic, then `SelectedReader.guard`, `package`, and
`open_signed` against the resulting fixture package. It does not install the T02
writer/controller or qualify protected Source8 inputs.

The host parent captures 1,703 exact repository-relative Source/API files by
held, single-link, nofollow reads and copies those bytes into a sparse snapshot.
It renders 27 roles plus three stage controls in a disposable family and selects
the exact stage and Source manifest. The first bubblewrap child receives only
that snapshot read-only, the family read-only, and `source/packages` writable.
The parent requires the closed Source success records, exact 36-member package
manifest, expected 68-leaf post-tree, unchanged staged leaves, and no extra
files or directories before constructing the Reader manifest.

The Reader manifest selects the just-verified Source and package manifests,
their complete input rows, and the generated role rows. Its digest, the Source
and package digests, and the stage-control digest are embedded in a separate
fixture bridge. The second bubblewrap child receives the same snapshot and
entire family read-only. It also has private tmpfs `/tmp` for the Reader's cold
replay. It opens the generated Reader, checks its distinct local types, runs
`SelectedReader.guard`, `package`, and `open_signed`, checks the selected
closure report, and requires refusal of wrong Reader, Source, and package pins.
The parent checks that the 69-leaf family and directory inventory are unchanged
afterward, bounds and hashes both children’s diagnostics, and verifies removal
of the owned scratch root after exit.

The first sealed successful observation is
`LC-U02-05/reader-probe-result-0001.json` (SHA-256
`3dca7e9d5b9e45b6138c943e85101b042422ae472620634b38dea2ab3f73c94e`).
The Reader selected 29 records and accounted for 582 replayed subjects. These
counts have different meanings: the Source builder’s 21 authored target records
do not equal the Reader’s filtered selected records. Source and Reader used a
fresh fixture signer; no private signer path or raw child diagnostics are in the
receipt. The Reader family tree was unchanged and scratch cleanup was observed.

This result is a disposable fixture check only. System Python, its standard
library, shared libraries, and distribution wheels were mounted/version-checked
but not cryptographically closed. Same-UID concurrent host mutation and global
Python module replacement are outside this scratch proof. The generated roles
are construction data, not a production controller or installed effect gate.
Mapper native effects, Context construction, G01/G02 protected issuer and owner
proof, actual WSL host qualification, formal LC-U02-05 acceptance, and activation
remain unproven. The selected formal runner graph still targets historical
`cases.json`; this probe is not runner-selected.

## Reachable final manifest, FINISH and close continuation

The original `build.py:71-77` calls `emit(out/'manifest.json', manifest)` and then prints its summary. It has **no** standalone FINISH call. The reviewed AST adapter replaces the complete `emit` write span with `_ctx_emit(p, encoded(value) if raw is None else raw)` while preserving the outer original call and byte choice. Select a new exact-byte **original-profile** bridge implementation of `_ctx_emit` whose manifest-only branch performs the following synchronously. This is a fixed bridge loaded by the selected module import, not a callback, monkey patch, shell wrapper or inferred postprocess. A pure AST/control-flow proof must show the original summary is unreachable until the branch returns; there is no second summary path.

1. For the 40th and final selected leaf only, require the earlier 39 durable leaf ACKs, the `RELEASE_PRIVATE` ACK and held private-root absence, the `build-result.json` ACK, exact manifest path/bytes, selected attempt and peer identity, current period and no previous completion attempt. Upload the **unchanged original** eight-field manifest bytes under the new original-profile writer contract. The mediator validates its schema `lab-actual-context-delivery-package/v1-candidate`, original claim string, 39 sorted exact bindings, source/delivery/provenance joins and no extras; the frozen inert writer's `lab-context-scratch-package/v1-inert` profile is not modified or substituted.
2. Send exactly one manifest EMIT. Require its **durable EMIT ACK**, including exact request/response hashes, ordinal, selected leaf digest and readback/fsync observation. A blob/buffer ACK is insufficient. A lost, malformed, late or wrong-peer manifest ACK is sticky UNKNOWN; never retransmit or infer success from an existing manifest.
3. Only after the valid EMIT ACK, send exactly one FINISH with an empty action payload and the next ordinal. FINISH is reachable **only** inside this final `_ctx_emit` continuation; no public second caller may invoke it. The mediator validates the complete original-profile 40-leaf/39-row package and source continuity, calls the held writer's final readback/close, checks its close result and private-root absence, and only then sends the exact FINISH ACK. It must not reuse the frozen inert `Server.receive_one` send-before-close path if that sends ACK before close. A repeated FINISH or late write is refused and poisons the attempt.
4. The bridge validates the FINISH ACK's closed fields: completion observation, exact ordinal, request hash, reconstructed model-request hash, schema and selected effect flag. It separately rechecks the final inventory digest from held bindings; it must not invent a digest field in the frozen ACK. It then closes its dedicated client endpoint **once** and checks the close outcome. Only after that checked close does `_ctx_emit` return to historical `build.py`, permitting its original summary print. A missing/lost/late FINISH ACK, mediator writer-close failure, client-close interruption or delayed teardown is UNKNOWN with no retry, re-emission, adopted directory or summary. If parent-side teardown fails after a client-visible summary, the enclosing controller verdict remains UNKNOWN and the printed line is nonfinal; final PASS requires later child exit, parent close, container absence and independent review.

The effect controller must bind this bridge's exact source hash, its import path, all request/ACK fields, deadline and the original-profile writer's exact source hash before one dispatch. A transcript must prove `RELEASE_PRIVATE → build-result EMIT ACK → manifest EMIT ACK → FINISH/mediator validation+writer close → FINISH ACK → checked client close → return → original summary`. No local fixture authority is inferred from the original `build-result.json` field `current_independent_host_permission:true`; parent evidence explicitly limits it to the self-provisioned development channel.

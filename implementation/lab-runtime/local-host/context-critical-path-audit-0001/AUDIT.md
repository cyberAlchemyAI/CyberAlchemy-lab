## Material integration traps

1. **Sibling layout is not already compatible.** Frozen Context `rendered/base.py`
   imports `HERE.parent/'mapped'`. Completed Mapper `base.py` instead derives
   ROOT via `HERE.parents[5]` and imports exact siblings
   `docker-source-20261020-0001` and `docker-reader-20261020-0001`.
   Blindly copying/renaming these to `source/reader/mapped` changes path-sensitive
   bindings and root derivation. Prefer preserving the completed snapshot's
   internal predecessor paths and explicitly projecting Context against them,
   if the exact projection permits it; otherwise version and verify every
   affected source/manifest binding. No symlink alias or silent pin repair.
   Distinct selected host/container paths must produce the same intended
   repository-relative and external bindings.

2. **59 public files are not a complete execution closure.** Closure0001 selects
   34 API v25, four Fact Scope and 21 carrier artifact/schema/fixture files.
   Its 1,804 historical rows include six excluded archives and 318 old-family
   candidates; those are not implicit imports. Context `base.package()` executes
   Mapper and API modules before `build.verify_source()`, and Fact Scope reuses
   a fixed module-cache name. A clean pinned loader/runtime must admit all source
   and transitive dependencies before these imports. A correct `__file__` alone
   does not authenticate a preloaded module. Include
   `_t35_external_runtime_capture` if retaining that rendered dependency reader.
   Python 3.14.4, jsonschema 4.23.0 and cryptography 46.0.5 must resolve to selected
   executable/module/native bytes; `-B` alone does not stop unselected pyc loads.

3. **Schema selection has a dynamic original join.** `generation.schema()`
   obtains seven schema paths/digests and admitted-current state from the
   actual selected Source view. The public API profile pin and seven fixture
   files do not prove those runtime values. Preserve that check in the real
   Source/Context path; refuse mismatch or unavailable contract, not fallback.
   `selected_mapping()` performs a fresh native read and exact byte parity with
   Mapper's retained native-output; prior Mapper PASS does not remove this call.

4. **JIT order and validity are separate from source freezing.** Authorization

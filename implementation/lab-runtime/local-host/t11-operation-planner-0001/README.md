# T11 local candidate operation planning

`plan.py` adds an operation-level producer and consumer to the previously reviewed 230-body fixture reader. It compiles the SHA-pinned router bytes, selects the frozen T11 matrix, issues an ephemeral **fixture** signature for each exact member/scope/body/admit route, and makes the router deliver the full selected body to `CandidatePlanner.prepare`. The planner checks the exact request, candidate identity and state, operation/category, expected per-scope head, and duplicate identity before producing a deterministic, effect-free plan record and successor plan head. The plan retains a *historical* decision reference for traceability; it does not treat that reference as a fresh authorization. No original bodies or authority files are modified.

The [RESULT.json](RESULT.json) contains 230 candidate plans in the matrix's selected order across six scopes (220, 6, 1, 1, 1, 1). Each record names the exact body binding and proposed `admit` effect, and has `planning_state=candidate-prepared` and `authority_effect=none`. The only state change is the planner's in-memory candidate ledger. A fresh run produces byte-identical JSON, even though it generates a new ephemeral fixture signing key, because signatures are not represented as Lab authority or retained in the result.

Run `python3 -B -m unittest implementation/lab-runtime/local-host/t11-operation-planner-0001/test_plan.py` and repeat with `python3 -O -B`; eight tests pass in each mode. Tests cover all 230 plans, one-member positive plus duplicate refusal, wrong scope/effect/target/body hash/stale head, wrong signer, changed delivered bytes, changed router code pin, unknown request field, and optimized replay identity.

This is a technical, local operation-plan route, **not** a native `operations.prepare` or `apply` call. The original T11 matrix still reports zero successful operational routes. Producer execution, current body/cut, governing owner and issuer grants, relation closure, native postimages, and original admission remain unproven. The planner pins bytes but does not establish the original filesystem locator if equal bytes are mirrored under a different root. T11 remains incomplete until all 230 are covered by actual native semantics or independently justified per-member equivalents with the missing current authority and source conditions.

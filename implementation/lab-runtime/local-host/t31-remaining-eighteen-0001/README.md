# Remaining original workflow transitions on the installed local cut

This directory prepares **actual** producer originals for the 18 transitions
outside the review-ready, failure, ontology and learning slice. It does not
turn an old source period, a historical decision, or a schema fixture into a
current permission or a successful workflow transition.

`prepare_api_configs.py` is an exact-selection adapter for stages whose output
records were returned by a successful current native Lab API call. It requires
the retained terminal and Vault original, matches the selected Source/profile,
checks every output revision and carrier against the original template, and
writes a new private `run_current.py` configuration with `O_EXCL`. It creates
no output record or authority effect. A transition counts only after the
final installed dispatcher commits it and passes exact retry and cold replay.

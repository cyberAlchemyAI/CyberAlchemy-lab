# Integration requirements

API66 is a focused short-deadline regression successor, not the final T15 cut.
Its new durable family retains the generic 21-record source. A final integrated
family must combine the current T03 Lesson and Evidence Set with their typed
relations and the selected T22 Work/Contract/contest lineage in one signed
4.23.0 source. Mapper counts, Context output inventory, exact native-disposition
subject count and all source/package/profile bindings must follow that actual
combined source; independent branch PASS receipts cannot be added together as
one-cut qualification.

The Session repair is portable: `current_legacy_context_sessions.py` prepares
schema-valid ephemeral metadata in its one original sealed fact scope;
`session_source_freshness.py` verifies all selected family/package/baseline
members and private archive; the Service calls `prepared_open_plan` only when
that method exists on its selected runtime. The source-family constants and
actual counts remain selected inputs, with no test-method AST rewrite.

# Integrated local fixture construction

This disjoint constructor combines the actual one-Lesson 4051 source recipe
with the API30 inspection Work and native Agent-contest Contract used by T22.
It creates signed local fixture records only. Repository authority, actual owner
outcomes, real protected inputs, and existing immutable source cuts are unchanged.

`stage_integrated.py` selects one fresh identity family. The generic 4051
Intent, Goal, Work, and Context are replaced by the API30-specific versions from
the tested T22 family after identity/path substitution. They are not unioned or
duplicated. A distinct Agent-only Challenge Contract is added. The existing
foundation operator Contract, repository-owner Principal, and historical Session
witness remain baseline inputs, with exact row equality checked by the audit.
The Lesson, Evidence Set and their two typed relations retain their meanings.

The new engine has its own loader, manifest, profile and pins. Its runtime code
is unchanged. Its profile adds the API30 manifest to signed baseline materials;
the current State and lookup were already present. Engine verification refuses
missing, extra or changed files in this selected closure. Native execution uses
the existing owned durable t22 installation and Python 3.14.4, jsonschema 4.23.0,
cryptography 46.0.5. The selected private archive stays outside the repository.

`phase_integrated.py` runs source, two independent cold replays, Reader,
Mapper and Context phases. Each phase creates its selected source manifest
before execution and writes a separate immutable result. `audit_integrated.py`
opens the actual signed Source again, checks actual counts and retained witness
rows, compares the actual original Intent/Goal/Work/Context field changes, and
checks Mapper and Context package outputs. Expected counts alone do not prove
construction.

# T32 selected native lifecycle writer interruption probe

`launch.py` checks and executes captured `run.py` bytes. The runner loads the selected `StoreFactory`/`GenerationStore` and original `NativeCandidateStore` from pinned source bytes. A disposable `FixtureTranslator` leaves rich mapping inert, while the factory-created `SelectedCandidateStore.append` override receives exact semantic/governance event pairs sealed by the pinned production native binary. Its wrapped `GenerationStore` invokes the pinned observer native binary for the append. The observer has explicit technical stop markers; the production binary is used for independent cold reads. Each interrupted child executes captured runner bytes through a private pipe.

The runner appends one baseline pair, then starts a fresh child for a second pair. It SIGKILLs the child at `after-lock`, `after-first-link`, and `before-cleanup` for both semantic and governance files. Two further cases use Python's line tracer on the exact pinned `GenerationStore.finish_publication` code to pause before and after the fsynced `HEAD` replacement, then SIGKILL the selected `append` child. Each pre-commit case verifies the old `HEAD` and event pair remain readable by the selected wrapper and production native reader, inserts an unknown file into the interrupted stage/generation and confirms detached recovery refuses without altering it or `HEAD`, removes only that test insertion, and recovers in a fresh process from the exact durable control. The post-commit case verifies the new pair is already readable and recovery is idempotent. All eight cases end with the exact two pairs in selected and production native reads, unchanged `HEAD` on retry, and preservation of an unrelated sibling.

Run `python3 -I -B implementation/lab-runtime/local-host/t32-selected-native-writer-0001/launch.py` and `python3 -O -I -B implementation/lab-runtime/local-host/t32-selected-native-writer-0001/launch.py` from the repository root only on new result versions. Both current runs wrote exclusive, fsynced `RESULT-0002.json` and `RESULT-OPT-0002.json`; the earlier replaceable `RESULT.json` is retained as a diagnostic. `python3 -B implementation/lab-runtime/local-host/t32-selected-native-writer-0001/verify.py` cold-checks both frozen receipts, all eight ordered cases and thirteen source/executable hashes. Four rehashed mutated receipts (missing case, wrong stage, false refusal, false child kill) were refused.

The [independent review](../working/t32-selected-native-writer-independent-review-0001/REVIEW.md) passed the selected writer/recovery behavior and the retained receipts within this stable-host technical scope. T32's local engineering check is complete. The fixture has no private source/issuer grant or rich translation; separate generation-publish fault placement, authenticated outer API integration, concurrent path replacement and host power loss remain outside this bounded result and are tracked by the relevant integration/release work.

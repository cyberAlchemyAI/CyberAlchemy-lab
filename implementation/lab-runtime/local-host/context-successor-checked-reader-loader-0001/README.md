# Checked staged Reader loader 0001 — inert candidate

This unit captures the selected, staged original `SelectedReader.open_signed` code closure into checked byte buffers. It never constructs `SelectedReader`, calls `open_signed`, opens `branch.snapshot`, signs a scope, issues AUTH, or creates an effect. It is independent of the held signed-scope controller 0001.

The capture uses the exact Reader manifest `048ef6c1f54387fc6e593f38b29723cb06f84649f12e9c75a0340d389b0f5756` and Reader code `f93a1f218238c05b18a7c355f9bc1363bbf42d2b1d442d03e191e121f8e9c9b9`; it rehashes the reviewed local issuer adapter 0002. It checks the exact 940 Source rows against the 948 Reader rows, plus the Source-package, engine, and parent-engine manifest joins. Held nofollow descriptor reads capture 40 code files and 85 public configuration files; the protected `branch.snapshot` body is explicitly excluded. Capture occurs only while the selected source period is current.

`checked_modules` executes captured buffers for the Reader/Source packages and their dynamic Source engine/bridge imports. It intercepts the original engine's temporary copied package name and supplies original captured engine-module buffers. An unselected staged dynamic code path or changed buffer is refused. The selected public configuration is rehashed before and after the inert import context. The original `SelectedReader.open_signed` method is located but not called. `observe_synthetic_scope` accepts a fake shape solely as a test and returns `SYNTHETIC_SCOPE_ONLY_NOT_ATTESTED`.

The loader is **not an effect release**. The original Reader/Source later open many source-manifest files and the protected archive by pathname. The captured Reader manifest has 948 rows and the Source manifest has 940; this unit does not virtualize all those reads or prove namespace continuity against a hostile same-UID replacement during actual invocation. A future effect controller must solve that boundary independently, along with the held claim-to-open attempt identity race. Third-party Python distributions are outside these captured buffers. The selected Source manifest requires Python 3.14.4, jsonschema 4.23.0, and cryptography 46.0.5. At this freeze, `/usr/bin/python3.14 -I -S` with `/usr/lib/python3/dist-packages` resolves jsonschema 4.19.2, so a real host `verify_source` would refuse. The real signed-scope observation, issuer/grant, AUTH row, private close, and Docker stage remain unexecuted.

Validation: 9/9 causal tests under `/usr/bin/python3.14 -B` and 9/9 under `-O -B`; selected code pathname reopening, mutated code/metadata, stale public configuration, incorrect dynamic paths, copied-engine mapping, and synthetic scope forgery are covered. No test opens the protected archive.

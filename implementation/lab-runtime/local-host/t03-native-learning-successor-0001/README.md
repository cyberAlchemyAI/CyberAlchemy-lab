# T03 native one-Lesson successor constructor

This is a disjoint successor of the retained T02 local native family recipe. It
adds one current, synthetic technical Operational Lesson to a newly signed
Source cut, maps that Lesson as a sixteenth native node, and builds a Context
with 26 mapped subjects and 31 generated carriers. The Context records one
exact Lesson inventory disposition and leaves `selected_lesson_refs` empty:
the separate live, authenticated `lesson.select` operation must decide
applicability from independent review, retention, instruction and source
witnesses. No old Lesson is revived. The selected sixth API33 package and
`legacy-local-947e6c2a5b3d10f8` remain unchanged.

The `stage_learning.py` wrapper first uses the retained fresh-family stage,
then transforms only five unselected files in the **new** instance. It updates
their exact rows in `construction-selection.json` and binds the transform,
constructor, evidence and cold fixture as additional runtime inputs before a
role source manifest is created. `construct_learning.py` differs from its T02
predecessor only in the asserted current Lesson inventory count. Each phase
uses original source, reader, native mapper and Context controls; normal
Source/Reader/Mapper/Context phase receipts are required before API rebinding.

Cold code checks (no source admission, native executable or Docker):

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest -v test_transform.py
PYTHONDONTWRITEBYTECODE=1 python3 -O -m unittest -v test_transform.py
```

When the shared runtime slot is free, create an owned external private
directory with mode 0700. Obtain the reviewed `source-manifest.json` SHA-256
from an independent release review, then pass it as
`--reviewed-manifest-sha256 <reviewed-sha256>` to `stage_learning.py stage
--private-home <absolute-external-directory>`. The stage prints the randomly
generated instance. Pass that exact instance and the same reviewed manifest
pin to phases `source`, `cold`, `reader`, `mapped`, `context` in order. A failed
phase consumes that instance; use a fresh one after a repair. The stage
selection and every phase result retain the reviewed manifest binding. A
missing or mismatched independent pin refuses before any phase work.

This package is prepared and cold-tested only. It does not claim the native
phases pass, a fresh API33 binding exists, a live Lesson is selected, an
Application or assessment occurred, or the T03 learning sequence completed.

   failure assessment and observations. Keep the open cause, exclusions,
   counterevidence, falsifier, expiry and explicit evidence retention policy.
2. Review exactly one Lesson revision and sign its isolated candidate Project
   transaction. This development fixture establishes local persistence only.
3. Invalidate the first Agent on HEAD change and erase its short memory.
4. Create a new Agent with independently replayed Project State and source-backed
   Context and Ontology Views. Reconstruct the committed lesson, not Session notes.
5. Filter exact current reviews and applicability. Retain exclusion reasons and
   incompatible lesson pairs. Selection creates zero Applications.
6. Apply the selected repair in an owned later case, capture actual process bytes,
   and assess the prediction against the observed outcome. Preserve uncertainty.
7. Propose an Improvement Signal, Target and unapplied Effect. A future actual
   owner Decision remains unresolved; nothing is promoted automatically.

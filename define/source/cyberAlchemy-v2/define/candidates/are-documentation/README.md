# ARE documentation definition

This candidate defines a coherent manual for the existing Agent Reasoning
Engine product. It does not redefine ARE, approve Candidate 013, or authorize
publication.

The manual is intended to let a reader move from “what is ARE?” to a verified
local run, agent integration, operational diagnosis, evidence interpretation,
and safe contribution without reconstructing the product from research notes
and historical design records.

The machine-readable scope is in
[`ARE-DOCUMENTATION-DEFINITION-PACK.v1-candidate.json`](ARE-DOCUMENTATION-DEFINITION-PACK.v1-candidate.json).

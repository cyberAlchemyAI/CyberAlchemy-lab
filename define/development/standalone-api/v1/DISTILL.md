## Closure and recomposition

Smallest unit: exact request/capture/member bytes to candidate Pack/report and frozen closure. Responsibility, inputs, outputs and failure boundary are explicit. Splitting away member closure would leave an uninterpretable Pack; adding deployment/auth/model orchestration would exceed this responsibility. Local files, Lab registry snapshots and future systems translate to the same capture contract. Consumers retain/export/review output through their own authority routes.

## Evolution and deferred work

Expected variants: agent authors, CLI users, Python apps and remote wrappers. Preserve one versioned data boundary. Defer streaming, authenticated standing verification, hosted HTTP/MCP transports, provider discovery and native v3 Lab publication until a concrete consumer requires them. The explicit snapshot adapter is sufficient for current Lab source reuse.

Premortem: installed package still reaches a repository-relative resource, or a generic catalog is mistaken for admitted authority. Guard with bundled resources, explicit version changes, no generic authority upgrade, source/package review and separately requested execution qualification.

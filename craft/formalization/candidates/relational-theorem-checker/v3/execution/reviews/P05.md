# P05 implementation review

Status: accepted by author implementation/review as a bounded candidate. This is not an independent security audit or issuer authentication.

## Plan and final design

The provenance reader resolves authoritative repo and pinned-toolchain bindings, and handles documentary captures only when the caller's explicit policy authorizes the exact capture. Required authoritative roots cannot be replaced by documentary entries. The compiler root and legacy exception-policy digest are fixed independently of submitted records.

The implementation checks current source closure with canonical-path/digest memoization and detects active artifact cycles. It records external governance JSON as exact-byte input leaves. It does not recursively import those leaves' historical governance claims. All 24 inherited exceptions retain exact origin bytes, selector, captured path and captured digest; no proof exception is introduced.

Saved audit reports have a closed schema. Rereading one checks every authoritative entry, its required root inventory, the pinned legacy policy, original legacy metadata origins and pinned toolchain copies. It does not patch another reader or redefine missing proof evidence as documentary.

## Gaps found and resolved

A JSON Schema property map contains keys named path and sha256 with schema objects as values. These are definitions rather than artifact references. The reader now recognizes a legacy reference only when both values are strings; explicitly tagged authoritative records still undergo strict field/type checks.

Saved reports needed their own strict validation on reread. Unknown fields, dropped required roots and expanded legacy policy are now rejected, alongside missing/stale proof sources, alternate compiler roots and path escape.

## Validation and limits

The actual inherited closure contains 4,147 distinct artifacts. Source audit, serialized-report round trip and exact exception-origin audit completed. All 46 controls passed, and the acceptance receipt's artifact/input bindings were rechecked after completion. Reports and code are under p05; the immutable predecessors remain inputs.

The memo saves duplicate hashing within an audit. The measured audit still traverses many compiled standard-library imports. It is not a cross-run authenticated cache. Filesystem and hashing remain trusted host assumptions, and a same-kernel proof is not an independent checker. No publication or live authority changed.

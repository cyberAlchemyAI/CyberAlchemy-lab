K01 candidate formalization review

This package prepares the proposed `addresses-improvement-target` meaning while
its actual human meaning assessment remains pending. It preserves the original
questioned definition, review manifest and clarification. It does not accept
N01, freeze successor contracts, or discharge an inherited obligation.

The source Research Inquiry schema has no Improvement Target field. Its required
question, Project, Goals, method, stopping conditions, source policy and research
boundary are separate from K01. The current raw fixture passes that schema without
an Improvement Target reference. `../../check_inquiry_scope.py` checks that fact
and five required-field refusal controls; see the clarification validation report.

The independent typed inquiry model includes Project/Goal/scope/method context,
source policy, inclusions, exclusions, stopping conditions, limitations, ownership
routes, evidence references and time context. A general theorem preserves this
projected inquiry validity when target, role and addressing-record catalogs are
empty. A synthetic instance is valid in that context while no K01 claim can hold.
This is a checked typed optionality witness, not the completed raw-source or
composed obligation-generator refinement.

The separate addressing predicate requires an independently captured intent
record for the exact inquiry/target/role, an exact target qualifier, a matching
owned role code and a complete matching frame. Refusal examples substitute the
target revision, role code, witness target, source snapshot or remove the primary
intent record. Recording appends that record and preserves resolution assessments,
comparisons, prioritization and protected state in the candidate state model.

Four independent outcome predicates allow evidence of resolution, measured
improvement, priority or bounded delegated authority. The synthetic model has a
valid addressing claim with each outcome absent. A second model has the same
addressing claim plus separate metric evidence of improvement. Non-entailment
therefore does not assert that improvement is always false.

Resolution needs positive evidence for every exact declared success measure and
no matching negative evidence. The candidate examples include both independent
complete resolution and refusal of conflicting positive/negative evidence. This
prepares the proposed successor conflict policy; it does not accept global D05
or change the accepted legacy any-positive-support profile.

Verification uses fresh compilation and separate fresh replay of all five modules
with the pinned compiler/library and per-theorem axiom inspection. The count,
source hashes, output hashes, logs and timings are in `verification.json`. The
failed preparation attempt is retained under `repair-attempts/01`.

Remaining gaps before the seven inherited K01 IDs can be discharged:

- Prove raw JSON and reference decoding, closed qualifier shape, exact source
  refinement and checker equivalence. The independent model is not a decoder.
- Complete Unicode nonblank checks, source list limits, duplicate/reference
  closure and timestamp parsing. The typed model's nonempty checks and Nat time
  order are candidate invariants; equality with the raw source contract is not
  established.
- Establish typed catalog ownership, non-equivocation, versioned review, complete
  frame capture, provenance authenticity and observation freshness. Context lists
  are trusted inputs here, not an authenticity proof.
- Review and formalize the addressing-role domain and actual role definitions.
  `investigate`, `compare` and `assessEvidence` are synthetic research-purpose
  examples, not an assigned production role catalog or implicit policy acceptance.
- Derive target closing criteria from complete owned success-measure definitions
  and prove the bridge to E03 fulfillment. Numeric Nat comparisons are a candidate
  metric example; supported units, precision and comparison policy need exact
  owned definitions.
- Bind measure assessments and comparisons to admissible source/action/output
  provenance and the reviewed conflict policy. Caller-supplied outcomes are not
  sufficient merely because they resemble these typed records.
- Include all relation rules and authority routes in the complete pinned theory,
  then replay each forbidden-inference countermodel and protected-state closure
  independently. This fragment only models the delegated-authority route.
- Implement qualification, revision idempotence, conflicting-content refusal and
  public/crash-safe recording. The state update above is a pure candidate delta.
- Prove the successor obligation generator preserves optional inquiry linkage:
  checking a K01 claim requires K01 obligations; checking an inquiry without one
  must not invent a mandatory Improvement Target dependency.

These gaps preserve the original complete-plan scope. All seven K01 inherited IDs
remain pending; the optionality obligation is additional integration work.

Separate reference types before choosing formulas. Candidate sorts should distinguish registry, entry, exact versioned Artifact Type reference, artifact-contract reference, schema-document reference, schema selector, content digest, discriminator path and discriminator value, semantic Definition reference set, owner decision reference, lifecycle overlay and token. Model the registry/entry membership relation explicitly. A total entry selector alone could hide duplicate declarations, so require a declared relation that binds an entry to its registry and exact type version. Determine whether uniqueness is local to registry/version, how duplicates are represented and whether multiple historical entries can legitimately reference one immutable contract. The source's one exact machine registry is a selected governance scope; it should not be translated into a global singleton across every mathematical domain or unrelated workspace without owner correspondence.

Each selected entry needs exact declared artifact, schema, digest, discriminator, Definition-set, owner-decision and lifecycle bindings. A digest token in T is a declaration. A selector may designate the whole schema or a valid region of shared schema bytes; applicability and resolution require explicit correspondence.

Keep registration, admission and currentness separate. Registration records an index membership. A candidate entry must not become admitted merely because it has an owner decision label. A declared lifecycle overlay binds a precise owner decision to the entry/type version; actual decision validity, authority, scope and lifecycle effect remain separate predicates. Currentness is determined by an exact owner decision overlay, not by a candidate status string embedded in an immutable package. Historical admitted versions stay represented after successors become current. Model candidate/admitted posture and current/historical disposition without collapsing these axes or fabricating unsupported lifecycle states.

The source requires each instance discriminator to resolve to at most one admitted current type.

# Next definition: Governance-Axis Independence Invariant

These are preparation notes for the next declared SWU, `F02-T.cal.definition.governance-axis-independence-invariant`. They add no interpretation, model result, acceptance or draft count. Gate remains the unit being delivered. The next unit must perform its own preservation preflight against the completed Gate seal.

The selected source describes a lifecycle tuple `L(a) = (kind, status, evidence, commitment, provenance, owner, residue)`. Its normative text lists six dimensions as minimum separations when relevant to a decision; the formal tuple includes residue as a seventh. Preserve that difference in a source finding rather than deleting residue, asserting a complete taxonomy, or treating the two lists as an accepted exact enumeration.

The first classification pass should distinguish the normalized invariant meaning, a declared lifecycle posture and a governance move. The invariant's artifact kind and carrier handle do not supply actual artifact lifecycle values or a complete status schema. A carrier recording the seven named components is a candidate representation of the retained core, not proof that every future artifact needs that exact record or that every artifact is an ontology node.

A proposed typed signature should separate subject identity, posture, move, axis identity, component value, information status and change record. Scope and version must be explicit. Each component may be known, unknown, deferred or source-local. These are information postures whose denotation needs review; they must not silently become four truth values. A source-local value also needs a source and interpretation binding rather than a universal status label.

The source says a governance move is valid only if it changes the intended component and does not imply changes to others unless those changes are explicitly recorded. Start from necessary conditions, not a sufficient validity rule. Distinguish intended axis, before/after posture, actual declared value differences, explicitly recorded additional changes and unsupported inferences. A schematic frame obligation is: for each relevant axis other than the intended one, its value is preserved or its change has a corresponding explicit record. Accepted move validity, record adequacy and actual execution remain separate obligations.

Clarify whether the intended axis must change value or whether an idempotent reaffirmation can count as a move. Clarify which dimensions are relevant at the selected scope, whether multi-axis moves have one intended axis or a declared intended set, and whether information-status changes count as component changes. The current source does not provide those complete operational semantics. Keep them in the finding ledger.

Independence requires useful shared-subject controls, not merely distinct sort names. Required candidate witnesses should preserve the given combinations: mature with weak evidence, well-evidenced imported source without local canonical authority, useful candidate without promotion, and committed owner without a hypothesis becoming authority. Suitable negative controls alter another component without a recorded change, or infer authority from maturity/evidence/commitment. Positive controls permit explicitly recorded additional changes when justified by the candidate rules. None establishes actual promotion, source fidelity or owner commitment.

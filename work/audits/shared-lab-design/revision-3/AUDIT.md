# Shared Lab revision 3 pre-implementation audit

**Verdict: complete the receipt issuance and join recovery contracts before wiring effects.** Revision 3 closes the tested substitutions after the planning envelope has been authenticated. The audit found a distinct upstream gap in how that envelope is issued, plus mismatches between the join continuation policy and the state machine.

| Finding | Evidence | Design acceptance criterion |
| --- | --- | --- |
| R3-01. Original receipt verification is an issuer obligation | verified-projection.mjs authenticates receiptBytes and checks one artifact digest, byte count, operation, scope and cut. It takes no original receipt bytes or source artifacts. VERIFIED-PROJECTION.json describes the upstream work in issuance and receipt_subjects. The wire schema defines a generic envelope and some domain artifacts, with no typed issuance request, verified member provenance or required original evidence set per decision route. | Specify the issuance input and output with exact original receipt and artifact bindings, predicate-specific verification policy, expected subject, member projection, and overlap checks. Identify which receipts are required for each route, including replay, refusal and unknown. Exercise the issuer with a changed artifact and the old original receipt before minting an envelope. |
| R3-02. A direct publication refusal has no matching edge | JoinContinuation returns PreserveRefusal for PublicationPrepared with a committed native draft and a proven publication refusal. JoinLifecycle rejects ObserveRefusal from PublicationPrepared. The refusal edge exists only after PublicationUnknown on the publication side. | Define the direct refusal transition or explicitly model a retained nonterminal recovery state. Preserve the native draft receipt and record that canonical selection did not change. |
| R3-03. Recovery after publication can stop at the stale-cut guard | JoinContinuation checks changedSource before CanonicalPublished and SourceTransitionPending. A previously published run returns Stale when the current cut differs. The design separates authoritative selection from later source observation, so the latter needs its own expected and observed cut contract. | Distinguish stale pre-effect work from historical reconciliation. Bind the original published snapshot and selector receipt, the intended observation target and the current selection. Specify what happens when the published snapshot has since been superseded. |
| R3-04. Continuation and transition evidence leave phase consistency to the issuer | Completed with unresolved native and publication outcomes returns PreserveCompleted. The transition guard checks signal and outcome, while generic join-transition evidence and a Bool result leave domain, destination and persisted observation correlation outside the decision. | Define the authoritative terminal receipt and contradiction handling. Bind a domain-specific past fact to prior phase, source cut, operation, revision, outcome, destination and resulting receipt. Define the exact transition proposal consumed by journal CAS, including replay versus conflict. |

The R3-01 witness authenticates a synthetic envelope pin. Its success establishes the projection boundary's scope. It neither demonstrates forged real authority nor exercises a real issuer. The compiled join witnesses show decision and topology behavior under synthetic observations. The stale-cut and terminal cases require a contract for the input situations that may occur in recovery. A future verifier rejecting inconsistent observations could satisfy the terminal case if that rule and its regression are explicit.

The 203 retained checks cover the four revision 2 regressions, including three changes to artifact bytes after envelope issuance, and the six outcomes against all 19 declared edges. That matrix establishes outcome gating on the declared topology. Direct refusal, cut changes after publication, and phase/outcome consistency require checks across both continuation and transition. The new witnesses target those interactions.

The next design pass should specify original-receipt issuance and the join recovery contract. Add regressions for stale original receipts, missing or conflicting original evidence, direct refusal, superseded publication and contradictory terminal evidence. Run each through the relevant issuer, projection and planning route. This audit found contract and topology gaps in the existing meanings.

This is evidence-backed guidance, not an admitted policy replacement.

| Boundary | Observed rule or guard | Current gap / recommendation |
| --- | --- | --- |
| Define → Lab | lab_bridge imports runtime/v2; exact context/freshness and current Definition checks | Explicit adapter to selected common context/change/review target, retaining old protocols |

| Ontology → global relation | Ontology-local mappings have separate namespaces/closure | Do not infer global Typed Relation from a field, local Edge or task-local application |

## Drift signals to investigate

- A new candidate directory is treated as the selected runtime without an exact binding.
- A provider hashes one file read but consumes a later read.
- An old source digest is silently replaced to make a changed registry appear current.
- A local signer/role label is accepted as a human or repository-owner effect.
- A stored lesson is counted as a used and beneficial lesson.
- A schema/finite-model result is counted as arbitrary semantic equivalence or production conformance.
- Documentation or source indexes claim current coverage without their exact source cut.

# Lab release → instance adoption

Direction: a versioned capability selection is offered to an instance; the instance applies its own compatibility and transition contract.

Observed building blocks: [Craft component selection](../../../../craft/implementation/bindings.json), [provisioning](../../../../implementation/lab-provisioning/candidates/v1/README.md) and [installation source](../../../../product/lab/release-candidates/v1/interface/api-installation-release-v4/installation_release.py).

Proposed join: [whole-Lab adoption](../../EVOLUTION.md) binds release/components, local Project/Product references, authority, extensions, migration and verification. No universal existing contract or global update is asserted.

Authority boundary: a parent release does not decide local owner effects merely through containment or shared dependency access.

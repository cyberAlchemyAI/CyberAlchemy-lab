# Foundations

The [architecture matrix](../ARCHITECTURE.md) separates five responsibilities across eight areas. A Project is a durable coordination identity; a Lab workspace is a proposed operational instance convention. Local instance content and reusable management behavior remain distinct. Project State spans governed records across the workspace.

Observed precedents include [Craft's current structure](../../../workspaces/products/craft/README.md), [its component bindings](../../../workspaces/products/craft/implementation/bindings.json), [source-profile continuity](../../../implementation/lab-runtime/v2/SOURCE-PROFILE-REPAIR.md), and [existing install/upgrade operations](../../../product/lab/release-candidates/v1/packaging/R02/OPERATIONS.md).

The [capability map](../CAPABILITY-MAP.md) records existing implementations, the [migration map](../MIGRATION-MAP.md) records candidate destinations, and the [evolution model](../EVOLUTION.md) proposes their common adoption join. None of these creates a new runtime selection.
